세피리아(Sephiria)의 석판·아티팩트 배치를 계산하고 게임 화면에 보여 주는 비공식 도우미입니다. 제안된 배치를 손으로 따라 옮기거나 `F8`로 적용할 수 있으며, 상자·상점·세피라이트의 후보와 석판 합성도 추천합니다.

TEAM HORAY와 제휴·후원·공식 승인 관계가 없는 무료 팬 제작 도구입니다. 소스와 배포본이 모두 이 저장소에 있으며 MIT 라이선스입니다.

**[안정 버전 다운로드](https://github.com/nyabi-gh/SephPlanner/releases/latest) · [전체 버전·변경 사항](https://github.com/nyabi-gh/SephPlanner/releases) · [오류 제보](https://github.com/nyabi-gh/SephPlanner/issues) · [문의](#문의)**

Windows용 Steam 세피리아에 설치하며, 게임은 별도로 필요합니다. 배포 ZIP에는 BepInEx 5.4.23.5(win_x64, Mono)가 포함되어 있습니다.

`Pre-release`가 붙은 시험 버전은 전체 버전 목록에서 확인할 수 있습니다. 설치할 파일은 각 릴리스의 `SephPlanner-v버전.zip`입니다.

## 설치

### 처음 설치하는 경우

1. 게임을 종료합니다.
2. [Releases](https://github.com/nyabi-gh/SephPlanner/releases)에서 `SephPlanner-v버전.zip`을 받습니다. GitHub가 표시하는 `Source code (zip)`은 설치 파일이 아닙니다.
3. 압축을 풀고 `SephPlanner` 안의 **`게임 폴더에 복사` 폴더를 엽니다.**
4. Steam에서 세피리아 우클릭 → **관리 → 로컬 파일 보기**로 게임 폴더를 엽니다.
5. `게임 폴더에 복사` **안의 내용물**을 게임 폴더에 복사합니다. 폴더 자체를 통째로 넣지 마세요.
6. 게임을 실행합니다. 첫 실행에는 데이터 준비가 필요하며, 탐험에 들어가면 게임 화면에 배치 도우미가 나타납니다. 별도 프로그램을 실행할 필요는 없습니다.

설치 후 주요 파일 위치는 다음과 같습니다.

```text
Sephiria/
├─ Sephiria.exe
├─ winhttp.dll
├─ doorstop_config.ini
└─ BepInEx/
   ├─ core/
   └─ plugins/
      ├─ SephPlanner.Plugin.dll
      └─ SephPlanner.Core.dll
```

ZIP에는 `설치안내.txt`, 사용 조건인 `LICENSE.txt`, 제3자 라이선스, 파일 확인용 `manifest.json`도 들어 있습니다. 게임 파일은 포함하지 않습니다.

### 이미 BepInEx를 사용하거나 이전 버전에서 업데이트하는 경우

게임을 종료하고 ZIP의 `게임 폴더에 복사/BepInEx/plugins`에 있는 **DLL 두 개를 모두** 게임의 `BepInEx/plugins`에 덮어쓰세요.

- `SephPlanner.Plugin.dll`
- `SephPlanner.Core.dll`

다른 모드에 사용하는 BepInEx 로더는 그대로 유지합니다. 이전 SephPlanner DLL을 다른 하위 폴더에 중복으로 남기지 마세요. 업데이트할 때 설정 폴더를 지울 필요는 없습니다. 필요한 카탈로그 갱신은 자동으로 진행되며, 준비가 끝나지 않거나 인식이 이상하면 게임 안에서 `F9`로 데이터를 다시 만들 수 있습니다.

## 기본 사용법

탐험 중 현재 가방의 점수와 제안 배치의 점수를 보여 줍니다. 펼친 화면에는 배치 격자와 이동 안내가 나오며, 금색 테두리는 달라지는 자리를 뜻합니다. 칸이나 후보에 커서를 올리면 효과·레벨·추천 근거를 볼 수 있습니다.

상자·상점 등에서 선택지가 보이면 후보 추천이 나타납니다. 상점에서 사파이어로 보충한 칸의 물건도 함께 읽습니다(0.3.9). 후보 추천이 켜져 있으면 선택지가 나타나거나 합작 NPC의 석판 합성 창을 열 때 패널도 자동으로 펼쳐집니다. 합작 추천을 보려고 상인에게 먼저 말을 걸 필요는 없습니다. 가까이 있다는 이유만으로 닫힌 상자의 내용을 보여 주지는 않습니다.

| 기본 키 | 기능 |
|---|---|
| `F1` | 후보를 획득했을 때의 배치를 차례로 미리보기. 마지막 다음은 현재 가방 배치로 복귀 |
| `F2` | 빌드 창: 프리셋 코드, 콤보 우선순위, 강화 우선·양보·사용 유지·끄기 허용·레벨 제한·강화 대상·제한 해제 칸 고정 |
| `F3` | 설정 창: 표시, 크기, 위치, 불투명도, 추천, 갱신 주기, 단축키, 진단 전송, 멀티 자동배치 |
| `F4` | 패널 숨기기·다시 표시. 숨겨도 계산은 계속 진행 |
| `F5` | 패널 불투명도 변경 |
| `F6` | 패널 이동 시작·종료. 이동 중 커서를 따라오며 다시 누르면 위치 저장 |
| `F7` | 패널 접기·펼치기 |
| `F8` | 현재 가방의 제안 배치 적용. 후보 미리보기 중에는 먼저 미리보기 종료 |
| `F9` | 게임 데이터 다시 생성 |
| `F10` | 진단·스냅샷·마지막 게시 계획의 재현 자료 저장. 동의한 경우 비공개 서버로 전송 |

화면에 표시되는 단축키가 위 표와 다르면 `F3`에서 변경된 키를 확인하세요. 빌드·설정 창은 마우스로 조작할 수 있으며, 싱글플레이에서는 창을 연 동안 게임 시간이 멈춥니다.

### 단축키 변경

`F3` → 단축키 탭에서 바꿀 키 이름을 누르고, 기존에 누르고 있던 키를 놓은 뒤 원하는 키를 입력합니다. 일반 키와 Ctrl·Alt·Shift 조합을 지정할 수 있으며 왼쪽·오른쪽 수정키를 구분합니다.

- `Esc`는 지정 취소, `해제`는 미지정, `기본값`은 원래 F키로 복원입니다.
- 키를 지정하는 동안에는 SephPlanner의 단축키 실행이 멈춥니다. 게임과 다른 모드의 입력까지 막지는 않습니다.
- `!` 표시는 충돌 가능성이나 설정 창 키가 해제됐다는 안내입니다. 충돌한 다른 기능의 키를 자동으로 바꾸지는 않습니다. 다른 모드의 키와 게임에서 직접 바꾼 키도 확인하세요.
- 설정 창을 여는 키를 해제했다면 창을 닫기 전에 다시 지정하세요. 이미 닫았다면 게임을 종료하고 `BepInEx/config/dev.nyabi.sephplanner.bridge.cfg`의 `SettingsKey`를 `F3`으로 복원할 수 있습니다.

이 문서의 `F1`~`F10`은 기본값입니다. 직접 변경했다면 해당 기능에 지정한 키를 사용하세요.

### 배치를 적용할 때

- **수동 배치:** 이동 안내를 위에서부터 따라갑니다. `↔ 교환`은 두 칸을 드래그로 맞바꾸라는 뜻이며 가방이 꽉 차 있어도 가능합니다. 회전은 최종 자리에서 안내합니다.
- **자동 배치:** `F8`로 현재 가방의 제안을 적용합니다. 게임 상태와 계산 결과를 검증하며, 상태가 달라졌거나 검증에 실패하면 실행하지 않습니다.
- **후보 미리보기:** 아직 획득하지 않은 아이템까지 포함한 예상 배치입니다. 점수에 `미리보기`가 표시되며, `F8`을 누르면 현재 가방 배치로 돌아옵니다. 돌아온 배치를 확인한 뒤 다시 눌러야 적용됩니다. 후보를 자동으로 구매하거나 획득하지는 않습니다.

점수는 배치를 비교하기 위한 도구 자체의 평가값입니다. 게임의 공식 전투력 수치가 아니며, 탐색 결과가 수학적으로 가장 좋은 배치임을 보장하지 않습니다. 추천에는 능력치 기반 평가와 희귀도에 따른 추정이 함께 쓰이므로, 고유 효과와 원하는 플레이 방식도 함께 판단해 주세요.

### 기본 활성 보호와 감점 칸 정리

현재 정상적으로 사용 중인 아티팩트와 지원 연결을 보호하고, 꺼진 아티팩트는 배치로 복구할 수 있는지 함께 검토합니다. 보석 갑옷·은팔찌처럼 이득과 패널티가 함께 있는 아이템도 같은 기준을 적용합니다. 효과 점수가 낮다는 이유만으로 사용 중인 효과를 끄지는 않습니다. 자체 활성 효과가 없는 아이템의 감점 칸 활용은 아래 아이템 배치 규칙을 따릅니다.

`양보`는 좋은 강화 칸을 다른 아이템에 양보하는 설정입니다. 효과를 꺼도 되는 아이템은 F2에서 별도로 `끄기 허용`을 켜세요. `사용 유지`를 함께 지정하면 사용 유지가 우선합니다. 무기 불일치나 지원 대상 부재처럼 자리 이동만으로 해결할 수 없는 이유도 있습니다. 끄기 허용 없이 현재 사용 중인 효과를 끊는 배치나 `사용 유지` 조건을 위반하는 배치는 자동 적용하지 않습니다.

같은 필수 조건과 효과를 만족하는 배치끼리는 감점·비활성 효과가 없는 빈칸을 더 확보하고, 상한을 넘겨 낭비하는 강화와 이동을 줄입니다. 경쟁 같은 석판도 강화 효과를 유지하면서 감점을 가방 밖으로 뺄 수 있는 배치를 검토합니다. 구석으로 옮기면 실제 효과가 줄어드는 경우까지 무조건 구석을 선택하지는 않습니다.

화면의 `활성 보존 우선`, `감점 칸 정리`, `배치 정리`는 효과 점수 외의 이유로 배치가 달라졌다는 안내입니다. 획득·빼기·교체·합성 추천에서도 현재 사용하는 다른 아티팩트의 활성 상태를 보호합니다.

### 하나 빼기 검토

펼친 화면에서 아이템 하나를 가방에서 빼고 재배치하면 점수가 나아지는 후보를 최대 세 개 보여줍니다. 쪽지에서 현재 위치와 활성 상태가 달라지는 아티팩트를 확인할 수 있습니다. 콤보 단계가 유지되는 후보만 표시하고, 개수가 줄면 따로 알립니다.

**`F8`은 아이템을 제거하지 않습니다.** 후보를 직접 뺀 뒤 다시 계산된 배치를 확인하고 적용하세요. 후보 추천을 끄면 이 기능도 꺼집니다. 둘 이상을 함께 빼는 조합이나 모든 가능한 배치를 검토하지는 않습니다. `사용 유지`로 지정한 아티팩트는 이 추천에서도 보호합니다.

### 빌드 지정 (`F2`)

상단 `빌드 초기화`는 가져온 빌드 코드와 콤보·강화 우선·양보·사용 유지·끄기 허용·레벨 제한·강화 대상·고정을 한 번에 해제합니다. 가방에 없는 아이템의 지정도 지우며, F3의 단축키·화면 설정은 유지합니다. `지우기`는 가져온 빌드 코드만 제거합니다.

- **빌드 코드:** 게임의 커스텀 로드아웃 코드를 복사하고 `빌드 코드 붙여넣기`를 누릅니다. 즐겨찾기 아티팩트와 양수 콤보 카테고리를 추천에 반영합니다. 회피 콤보는 현재 추천에 반영되지 않으며 창에 이를 표시합니다.
- **콤보 우선순위:** 밀고 싶은 콤보를 눌러 지정하거나 해제합니다. 프리셋을 교체·삭제하면 가져온 우선순위도 바뀌고 수동 지정은 유지됩니다. 캘세더니 열쇠·하얀 종이·북향의 침처럼 위치에 따라 콤보가 달라지는 배치에도 반영합니다. 지정 때문에 일반 점수가 낮아지면 `지정 콤보 우선`으로 표시하고, 조건을 만족하는 배치를 찾지 못하면 이유를 알립니다.
- **강화 우선·양보:** 아티팩트를 좌클릭하면 `★` 2배 → `★★` 4배 → `★★★` 10배 → 해제 순으로 바뀝니다. 우클릭은 `▽` 0.5배 → `▽▽` 0.25배 → `▽▽▽` 0.1배 → 해제 순입니다. 반대 방향으로 누르면 한 단계씩 돌아오며, 0단계는 지정 해제입니다. 좋은 자리를 얼마나 우선해서 배정할지 정하며 레벨 상한을 올리지는 않습니다. **배수는 이득에만 적용하고 패널티는 그대로 반영합니다.** 조화의 수정 등 반영된 이웃 효과에도 같은 기준을 씁니다. 양보를 지정해도 기본 활성 보호는 유지됩니다.
- **`사용 유지`:** 소유한 같은 종류의 아티팩트 전부를 활성 상태로 유지하는 배치를 점수보다 우선합니다. 빼기·교체 추천에서 보호하고, 다른 아이템이나 석판을 바꿔 간접적으로 꺼뜨리는 추천도 제외합니다. 조건을 만족하는 배치를 찾지 못하면 이유를 표시하고 자동 배치를 멈춥니다. 무기 불일치처럼 자리 이동으로 해결할 수 없는 이유도 있습니다.
- **`끄기 허용`:** 해당 종류의 아티팩트는 다른 강화 이득을 위해 효과를 꺼도 된다고 지정합니다. 항상 끄는 명령은 아니며, 강화 우선·양보와는 별도로 저장됩니다. `사용 유지`와 함께 켜면 사용 유지가 우선합니다.
- **`고정`:** 해당 아티팩트를 배치 조건을 무시하는 효과가 있는 칸에 놓도록 합니다. 특정 좌표나 회전을 고정하는 기능은 아닙니다. 해당 칸이 모자라면 경고와 함께 이 조건을 완화합니다.
- **`레벨 제한`:** 그 아티팩트를 지정한 레벨까지만 값으로 칩니다. 좌클릭으로 1, 2, 3… 으로 올라가고 우클릭으로 되돌립니다. **남는 높은 칸이 다른 아티팩트에게 돌아갑니다** — "이건 3레벨이면 충분하다"를 별로는 말할 수 없어서 넣었습니다. 막는 것이 아니라 값을 안 쳐 주는 것이라, 그 칸을 아무도 원하지 않으면 여전히 거기 놓일 수 있습니다.
- **`대상`:** 북향의 침과 빛나는 모래시계가 그 아티팩트를 강화하도록 지정합니다. **점수보다 우선합니다** — 도구가 다른 대상을 더 좋게 보더라도 지정한 쪽으로 갑니다. 침이나 모래시계를 들고 있고 그 대상이 될 수 있는 줄에만 단추가 나옵니다. 닿을 수 없으면 배치를 포기하지 않고 그 지정만 무시하며 이유를 표시합니다.

후보 추천을 꺼도 배치 계산과 콤보 우선순위·강화 우선·양보·사용 유지·끄기 허용·레벨 제한·강화 대상·고정 지정은 사용할 수 있습니다. 빌드 설정 저장에 실패하면 창에 경고가 나오며, 다음 설정 변경 때 다시 저장을 시도합니다.

### 모래시계와 마법의 연결

빛나는 모래시계는 **바로 오른쪽 칸의 사용 가능한 마법**을 강화합니다. 이 효과를 배치 점수에 반영하고, 모래시계와 마법을 함께 옮기는 배치도 검토합니다. 대상은 볼트로 한정되지 않으며, 다른 사용 가능한 마법으로 연결이 바뀔 수 있습니다.

모래시계의 `사용 유지`를 켜면 마법과의 유효한 연결까지 보호합니다. 강화 대상을 없애거나 꺼뜨리는 빼기·교체·합성 추천도 제외하며, 연결할 수 없으면 이유를 표시하고 자동 배치를 멈춥니다. 모래시계 자체가 활성이라고 해서 연결 보너스까지 적용되는 것은 아닙니다.

어느 마법을 강화할지는 `F2`에서 그 마법의 `대상`을 눌러 직접 지정할 수 있습니다. 마법서는 값어치가 희귀도 기준 추정이라 도구가 "어느 마법을 실제로 쓰고 있는지"를 알 수 없기 때문입니다. 지정하면 점수보다 우선해 그 마법과 연결하는 배치를 고릅니다.

강화 가치는 대상 마법과 회복 속도를 기준으로 한 추정입니다. 추가 버프·마나·실제 시전 빈도까지 계산한 전투 효율은 아닙니다.

### 북향의 침과 행성

북향의 금빛 침·푸른 침은 바로 위의 공격 가능한 아티팩트를 강화하고 그 대상의 콤보를 물려받습니다. 침이 이어져 있으면 마지막 대상을 따라갑니다. 석판이나 공격할 수 없는 아티팩트는 강화 대상이 될 수 없습니다.

**무엇을 강화할지는 `F2`에서 그 아티팩트의 `대상`을 눌러 지정할 수 있습니다.** 특정 좌표를 고정할 필요는 없습니다. 행성에 연결하고 싶다면 이 지정을 쓰거나, 전처럼 `행성` 콤보를 지정해도 됩니다.

침은 대상이 언커먼 이하일 때 게임 규칙에 따라 덤을 더 받습니다. 0.3.9부터는 그 덤을 대상이 얼마나 센지와 함께 견주므로, 값싼 아티팩트만 골라 강화하지 않습니다.

## 0.3.3의 아이템 배치 규칙

- **대립의 천칭:** 자동 배치에서 현재 놓인 쪽을 유지합니다. 왼쪽은 1~3열, 오른쪽은 4열 이후이며 같은 쪽 안에서는 이동할 수 있습니다. 방향을 바꾸려면 직접 반대쪽으로 옮기세요. 보유한 천칭은 획득·제외·합성 추천에서도 같은 규칙을 따릅니다.
- **마음의 짐:** 자체 활성 효과가 없는 아이템은 감점 칸을 활용해 다른 아이템의 자리를 확보합니다. 주변 효과와 사용 유지·고정을 함께 고려하므로 무조건 감점 칸에 놓지는 않습니다.
- **버릴 수 없는 아이템:** 제외·교체 추천에서 보호합니다. `F8`은 아이템을 제거하지 않습니다.
- **친타마니 돌:** 발동 후 남는 칸 레벨 보너스를 반영합니다. 아이템을 옮겨도 보너스는 원래 칸에 남습니다.


## 다른 모드와 함께 사용할 때

기존 BepInEx 환경에서는 SephPlanner의 DLL 두 개만 추가·교체하세요. 모든 모드 조합을 검증한 것은 아니므로 인벤토리·석판 효과·게임 입력을 바꾸는 모드를 함께 사용한다면 동작을 확인해야 합니다. 단축키가 겹치면 `F3`에서 변경하고, 문제가 생기면 사용 중인 다른 모드의 이름과 버전도 함께 제보해 주세요.

## 멀티플레이

멀티 자동배치는 **기본적으로 꺼져 있는 실험 기능**입니다. 읽기와 추천은 사용할 수 있으며, 함께 플레이하는 사람들의 동의를 받은 뒤 `F3`의 `멀티 자동 배치(실험)`에서 적용 기능을 켤 수 있습니다.

켜면 방을 연 사람과 참가한 사람 모두 사용할 수 있습니다. 참가자는 서버 반영을 한 걸음씩 확인하므로 시간이 걸릴 수 있습니다. 적용 중에는 가방을 직접 조작하지 말고 완료 안내를 기다려 주세요.

**서버 반영이 불확실하다는 경고가 나오면 추가 이동과 되돌리기를 중단하고 자동배치가 잠깁니다.** 앞선 명령이 늦게 도착할 수 있으므로, 안내대로 방에 재접속한 뒤 다시 사용하세요.

## 문제가 있을 때

| 증상 | 확인할 사항 |
|---|---|
| 패널이 보이지 않음 | 탐험에 들어갔는지, `F4`로 숨긴 상태인지, `F3`의 화면 표시가 켜져 있는지 확인합니다. 설치 경로와 DLL 두 개도 확인하세요. |
| 첫 실행에 데이터 준비 중 | 준비가 끝날 때까지 기다립니다. 계속 진행되지 않으면 아래 로그와 함께 제보하세요. |
| 패치 후 인식·계산 이상 | `F9`로 데이터를 다시 만들고, 문제가 남으면 `F10`으로 상태를 저장합니다. |
| 게임 상태와 계산 결과 불일치 | 해당 안내는 자동배치 잠금 사유입니다. `F10`으로 상태를 저장하고 아래 제보 안내에 따라 화면의 경고와 함께 알려 주세요. |
| 최신 계획 계산 중·계산이 오래 걸림 | 계산이 끝난 뒤 다시 시도합니다. 오래 걸리거나 계속 반복되면 `F10`으로 상태를 저장하고, 대략적인 대기 시간과 기다렸을 때 결과가 나오는지를 로그·화면 안내와 함께 알려 주세요. |
| 서버 반영 불확실·재접속 필요 | 방에 재접속합니다. 단순히 키를 반복해서 눌러 잠금을 풀 수는 없습니다. |
| 활성 보호·사용 유지 배치를 찾지 못함 | 지정한 아이템과 화면에 표시된 이유를 확인합니다. 활성 칸·배치 조건·연동 무기 등을 확인하고, 모래시계라면 오른쪽에 사용 가능한 마법을 연결할 수 있는지도 확인하세요. |
| 아티팩트가 음수 칸으로 이동하거나 지원 연결이 끊김 | 해당 아이템의 `끄기 허용`·`사용 유지` 설정을 확인합니다. 문제가 남으면 `F10`으로 상태를 저장하고 기대한 배치와 실제 배치를 함께 알려 주세요. |
| 합작 NPC에서 추천이 보이지 않음 | `F3`의 후보 추천을 켰는지, `F4`로 숨긴 상태인지, 합성기를 이미 사용했는지 확인합니다. `F7`로 펼쳐 확인할 수 있으며, 합칠 수 있는 조합이 없으면 이유를 표시합니다. |
| 단축키를 눌러도 반응이 없음 | `F3`의 단축키 탭에서 지정·해제·충돌 표시를 확인합니다. 설정 창 키까지 해제했다면 위의 설정 파일 복원 방법을 사용하세요. |
| 설정 저장 실패 | 이번 실행에서는 지정이 유지되지만 다음 실행에 남지 않을 수 있습니다. 로그의 저장 오류를 확인해 주세요. |

### 제보에 필요한 정보

게임 안에서 문제가 발생한 상태로 `F10`을 누르세요. 처음 전송할 때 수집 항목을 확인하고 동의하면 이번 진단과 이후 F10 진단을 개발자가 운영하는 **비공개 서버**로 보냅니다. `F3`에서 자동 전송을 끌 수 있으며, 동의하지 않아도 로컬 저장은 사용할 수 있습니다.

전송 시작 간격은 1분입니다. 그 사이에 저장한 자료를 나중에 자동으로 보내지는 않으며, 전송 중에는 추가 전송을 시작하지 않습니다. 성공하면 표시되는 **제보 번호**와 함께 [Issues](https://github.com/nyabi-gh/SephPlanner/issues)에 다음을 알려 주세요.

- SephPlanner 버전과 게임 버전
- 싱글/멀티 여부, 멀티라면 호스트/참가자 여부
- 재현 순서, 기대한 결과와 실제 결과, 경고가 보이는 스크린샷
- 배치 문제라면 해당 아이템의 사용 유지·끄기 허용·고정·레벨 제한·강화 대상, 선택한 콤보와 강화 우선·양보 설정
- 계산 지연이라면 대략적인 대기 시간, 기다리면 결과가 나오는지, 후보 추천을 켰는지 여부
- 진단 제보 번호. 전송 실패 시에는 화면에 표시된 오류와 로컬 보관 여부

전송 자료에는 인벤토리 진단·스냅샷, 빌드 설정, 마지막 게시 계획의 재현 자료, SephPlanner의 최근 로그가 포함됩니다. 세이브·게임 DLL·전체 게임 폴더는 보내지 않으며, 전송용 로그의 사용자 경로 등은 가립니다. 로컬 원본은 바꾸지 않습니다.

Windows 탐색기 주소창에 `%LOCALAPPDATA%\SephPlanner`를 입력하면 로컬 진단 폴더를 열 수 있습니다. `inventory-dump.txt`와 `inventory-snapshot.json`은 최근 진단으로 갱신되고, 회차별 자료는 `reports`, 계획 재현 파일은 `reproductions`에 보관합니다. 게임 로그는 게임 폴더의 `BepInEx/LogOutput.log`에 있습니다.

`.replay`는 마지막으로 계산해 화면에 게시한 계획의 입력·설정·당시 데이터를 담습니다. 계산 중에 `F10`을 누르면 직전 게시 계획의 자료이므로 누른 순간의 스냅샷과 다를 수 있습니다. 아직 게시된 계획이 없다면 만들지 않고 안내합니다.

**진단 원본과 `.replay`에는 게임 데이터가 포함됩니다. 공개 Issues나 배포물에 첨부하지 마세요.** 전송하지 않았거나 전송에 실패했다면 자료를 로컬에 보관하고, 공개 제보에는 증상·스크린샷·오류 메시지만 남겨 주세요. 스크린샷이나 로그 문구에도 공개하고 싶지 않은 정보가 없는지 확인하세요.

도구를 제거한 상태에서도 재현되는지 확인하면 원인을 좁히는 데 도움이 됩니다. 제거 후에도 발생한다는 사실만으로 게임 자체의 문제라고 단정할 수는 없습니다. 다른 모드 사용 여부도 함께 알려 주세요.

## 제거와 설정 초기화

게임을 종료하고 `BepInEx/plugins`에서 `SephPlanner.Plugin.dll`과 `SephPlanner.Core.dll`을 삭제하면 플러그인이 제거됩니다. 다른 모드의 파일은 그대로 두세요.

설정도 초기화하려면 필요한 파일을 백업한 뒤 다음을 삭제합니다.

- `BepInEx/config/dev.nyabi.sephplanner.bridge.cfg`: 패널 표시·단축키 등
- `%LOCALAPPDATA%\SephPlanner`: 빌드 설정(`plugin-settings.json`), 카탈로그, 진단 파일 등

다른 모드를 사용한다면 BepInEx 로더는 제거하지 마세요.

## 사용 조건과 구성요소

모드 사용은 본인 책임이며, TEAM HORAY는 공식 모드 지원을 제공하지 않습니다. 모드로 생긴 문제는 개발사의 지원 대상이 아니므로 중요한 세이브는 미리 백업해 두세요.

SephPlanner는 MIT 라이선스입니다. 쓰고 고치고 다시 배포하는 것이 모두 자유이며, 저작권 표시만 함께 남겨 주시면 됩니다. **만드는 쪽은 비영리를 지킵니다** — 광고·후원·구독 어느 것도 붙이지 않습니다. 개발사의 모드 정책이 상업적 목적의 모드를 제재 사유로 두고 있어서이며, 포크하실 때도 그 점을 보아 주세요.

다운로드를 안내할 때는 파일을 다시 올리는 대신 이 저장소의 Releases 링크를 공유해 주세요. 조건이 아니라 부탁입니다 — 옛 버전이 돌아다니면 이미 고친 문제로 제보가 옵니다.

함께 배포되는 BepInEx와 Unity Doorstop은 각각의 라이선스를 따릅니다. ZIP의 `제3자-라이선스` 폴더에 라이선스 원문과 소스 위치가 포함되어 있습니다. 이 도구의 사용 조건을 게임이나 제3자 구성요소의 사용 조건으로 해석하지 마세요.

# SephPlanner

세피리아(Sephiria)의 석판·아티팩트 배치를 계산하고 게임 화면에 보여 주는 비공식 도우미입니다. 제안된 배치를 손으로 따라 옮기거나 `F8`로 적용할 수 있으며, 상자·상점·세피라이트의 후보와 석판 합성도 추천합니다.

TEAM HORAY와 제휴·후원·공식 승인 관계가 없는 무료 팬 제작 도구입니다. 이 저장소는 다운로드와 오류 제보를 위한 공개 저장소이며, 소스 코드는 공개하지 않습니다.

**[다운로드](https://github.com/nyabi-gh/SephPlanner-Release/releases) · [0.2.1 변경 사항](https://github.com/nyabi-gh/SephPlanner-Release/releases/tag/v0.2.1) · [오류 제보](https://github.com/nyabi-gh/SephPlanner-Release/issues)**

이 안내는 0.2.1 기준입니다. Windows용 Steam 세피리아에 설치하며, 게임은 별도로 필요합니다. 배포 ZIP에는 BepInEx 5.4.23.5(win_x64, Mono)가 포함되어 있습니다.

## 설치

### 처음 설치하는 경우

1. 게임을 종료합니다.
2. [Releases](https://github.com/nyabi-gh/SephPlanner-Release/releases)에서 `SephPlanner-v버전.zip`을 받습니다. GitHub가 표시하는 `Source code (zip)`은 설치 파일이 아닙니다.
3. 압축을 풀고 `SephPlanner` 안의 **`게임 폴더에 복사` 폴더를 엽니다.**
4. Steam에서 세피리아 우클릭 → **관리 → 로컬 파일 보기**로 게임 폴더를 엽니다.
5. `게임 폴더에 복사` **안의 내용물**을 게임 폴더에 복사합니다. 폴더 자체를 통째로 넣지 마세요.
6. 게임을 실행합니다. 첫 실행에는 데이터 준비가 필요하며, 탐험에 들어가면 게임 화면에 배치 도우미가 나타납니다. 별도 프로그램을 실행할 필요는 없습니다.

설치 후 주요 파일 위치는 다음과 같습니다.

```text
Sephiria/
├─ Sephiria.exe
├─ winhttp.dll
├─ doorstop_config.ini
└─ BepInEx/
   ├─ core/
   └─ plugins/
      ├─ SephPlanner.Plugin.dll
      └─ SephPlanner.Core.dll
```

ZIP에는 `설치안내.txt`, 사용 조건인 `LICENSE.txt`, 제3자 라이선스, 파일 확인용 `manifest.json`도 들어 있습니다. 게임 파일은 포함하지 않습니다.

### 이미 BepInEx를 사용하거나 이전 버전에서 업데이트하는 경우

게임을 종료하고 ZIP의 `게임 폴더에 복사/BepInEx/plugins`에 있는 **DLL 두 개를 모두** 게임의 `BepInEx/plugins`에 덮어쓰세요.

- `SephPlanner.Plugin.dll`
- `SephPlanner.Core.dll`

다른 모드에 사용하는 BepInEx 로더는 그대로 유지합니다. 이전 SephPlanner DLL을 다른 하위 폴더에 중복으로 남기지 마세요. 업데이트할 때 설정 폴더를 지울 필요는 없습니다.

## 기본 사용법

탐험 중 현재 가방의 점수와 제안 배치의 점수를 보여 줍니다. 펼친 화면에는 배치 격자와 이동 안내가 나오며, 금색 테두리는 달라지는 자리를 뜻합니다. 칸이나 후보에 커서를 올리면 효과·레벨·추천 근거를 볼 수 있습니다.

상자·상점 등에서 선택지가 보이면 후보 추천이 나타납니다. 후보 추천이 켜져 있으면 선택지가 나타날 때 패널도 자동으로 펼쳐집니다. 가까이 있다는 이유만으로 닫힌 상자의 내용을 보여 주지는 않습니다.

| 기본 키 | 기능 |
|---|---|
| `F1` | 후보를 획득했을 때의 배치를 차례로 미리보기. 마지막 다음은 현재 가방 배치로 복귀 |
| `F2` | 빌드 창: 프리셋 코드, 콤보 우선순위, 강화 우선·양보·제한 해제 칸 고정 |
| `F3` | 설정 창: 표시, 크기, 위치, 불투명도, 추천, 갱신 주기, 단축키, 멀티 자동배치 |
| `F4` | 패널 숨기기·다시 표시. 숨겨도 계산은 계속 진행 |
| `F5` | 패널 불투명도 변경 |
| `F6` | 패널 이동 시작·종료. 이동 중 커서를 따라오며 다시 누르면 위치 저장 |
| `F7` | 패널 접기·펼치기 |
| `F8` | 현재 가방의 제안 배치 적용. 후보 미리보기 중에는 먼저 미리보기 종료 |
| `F9` | 게임 데이터 다시 생성 |
| `F10` | 현재 상태를 진단 파일과 재생용 스냅샷으로 저장 |

화면에 표시되는 단축키가 위 표와 다르면 `F3`에서 변경된 키를 확인하세요. 빌드·설정 창은 마우스로 조작할 수 있으며, 싱글플레이에서는 창을 연 동안 게임 시간이 멈춥니다.

### 배치를 적용할 때

- **수동 배치:** 이동 안내를 위에서부터 따라갑니다. `↔ 교환`은 두 칸을 드래그로 맞바꾸라는 뜻이며 가방이 꽉 차 있어도 가능합니다. 회전은 최종 자리에서 안내합니다.
- **자동 배치:** `F8`로 현재 가방의 제안을 적용합니다. 게임 상태와 계산 결과를 검증하며, 상태가 달라졌거나 검증에 실패하면 실행하지 않습니다.
- **후보 미리보기:** 아직 획득하지 않은 아이템까지 포함한 예상 배치입니다. 점수에 `미리보기`가 표시되며, `F8`을 누르면 현재 가방 배치로 돌아옵니다. 돌아온 배치를 확인한 뒤 다시 눌러야 적용됩니다. 후보를 자동으로 구매하거나 획득하지는 않습니다.

점수는 배치를 비교하기 위한 도구 자체의 평가값입니다. 실제 DPS나 게임의 공식 전투력 수치가 아니며, 탐색 결과가 수학적으로 가장 좋은 배치임을 보장하지 않습니다. 추천에는 능력치 기반 평가와 희귀도에 따른 추정이 함께 쓰이므로, 고유 효과와 원하는 플레이 방식도 함께 판단해 주세요.

### 빌드 지정 (`F2`)

- **빌드 코드:** 게임의 커스텀 로드아웃 코드를 복사하고 `빌드 코드 붙여넣기`를 누릅니다. 즐겨찾기 아티팩트와 양수 콤보 카테고리를 추천에 반영합니다. 회피 콤보는 현재 추천에 반영되지 않으며 창에 이를 표시합니다.
- **콤보 우선순위:** 밀고 싶은 콤보를 눌러 지정하거나 해제합니다. 프리셋을 교체·삭제하면 가져온 우선순위도 바뀌고 수동 지정은 유지됩니다. 구버전 설정의 기존 목록은 출처를 구분할 수 없어 보존합니다.
- **강화 우선·양보:** 아티팩트를 좌클릭하면 강화 우선 단계를 올리고, 우클릭하면 내립니다. 좋은 자리를 얼마나 우선해서 배정할지 정하는 설정이며 레벨 상한을 올리는 기능은 아닙니다.
- **`고정`:** 해당 아티팩트를 배치 조건을 무시하는 효과가 있는 칸에 놓도록 합니다. 특정 좌표나 회전을 고정하는 기능은 아닙니다. 해당 칸이 모자라면 경고와 함께 이 조건을 완화합니다.

후보 추천을 꺼도 배치 계산과 강화 우선 지정은 사용할 수 있습니다. 빌드 설정 저장에 실패하면 창에 경고가 나오며, 다음 설정 변경 때 다시 저장을 시도합니다.

## 멀티플레이

멀티 자동배치는 **기본적으로 꺼져 있는 실험 기능**입니다. 읽기와 추천은 사용할 수 있으며, 함께 플레이하는 사람들의 동의를 받은 뒤 `F3`의 `멀티 자동 배치(실험)`에서 적용 기능을 켤 수 있습니다.

켜면 방을 연 사람과 참가한 사람 모두 사용할 수 있습니다. 참가자는 서버 반영을 한 걸음씩 확인하므로 시간이 걸릴 수 있습니다. 적용 중에는 가방을 직접 조작하지 말고 완료 안내를 기다려 주세요.

**서버 반영이 불확실하다는 경고가 나오면 추가 이동과 되돌리기를 중단하고 자동배치가 잠깁니다.** 앞선 명령이 늦게 도착할 수 있으므로, 안내대로 방에 재접속한 뒤 다시 사용하세요.

## 문제가 있을 때

| 증상 | 확인할 사항 |
|---|---|
| 패널이 보이지 않음 | 탐험에 들어갔는지, `F4`로 숨긴 상태인지, `F3`의 화면 표시가 켜져 있는지 확인합니다. 설치 경로와 DLL 두 개도 확인하세요. |
| 첫 실행에 데이터 준비 중 | 준비가 끝날 때까지 기다립니다. 계속 진행되지 않으면 아래 로그와 함께 제보하세요. |
| 패치 후 인식·계산 이상 | `F9`로 데이터를 다시 만들고, 문제가 남으면 `F10`으로 상태를 저장합니다. |
| 게임 상태와 계산 결과 불일치 | 해당 안내는 자동배치 잠금 사유입니다. `F10` 파일과 화면의 경고를 함께 제보해 주세요. |
| 최신 계획 계산 중 | 계산이 끝난 뒤 다시 시도합니다. 계속 반복되면 로그를 첨부하세요. |
| 서버 반영 불확실·재접속 필요 | 방에 재접속합니다. 단순히 키를 반복해서 눌러 잠금을 풀 수는 없습니다. |
| 설정 저장 실패 | 이번 실행에서는 지정이 유지되지만 다음 실행에 남지 않을 수 있습니다. 로그의 저장 오류를 확인해 주세요. |

### 제보에 필요한 정보

게임 안에서 문제가 발생한 상태로 `F10`을 누른 뒤 [Issues](https://github.com/nyabi-gh/SephPlanner-Release/issues)에 다음을 함께 올려 주세요.

- SephPlanner 버전과 게임 버전
- 싱글/멀티 여부, 멀티라면 호스트/참가자 여부
- 재현 순서, 기대한 결과와 실제 결과, 경고가 보이는 스크린샷
- 게임 폴더의 `BepInEx/LogOutput.log`
- `%LOCALAPPDATA%\SephPlanner\inventory-dump.txt`
- `%LOCALAPPDATA%\SephPlanner\inventory-snapshot.json`

Windows 탐색기 주소창에 `%LOCALAPPDATA%\SephPlanner`를 입력하면 진단 파일 폴더를 열 수 있습니다. `F10`은 기존 진단 파일을 갱신하므로 필요한 상황을 저장한 뒤 파일을 따로 보관하세요. 공개 제보에 첨부하기 전에 로그에 개인 경로 등 공개하고 싶지 않은 정보가 있는지 확인해 주세요.

도구를 제거한 상태에서도 재현되는지 확인하면 원인을 좁히는 데 도움이 됩니다. 제거 후에도 발생한다는 사실만으로 게임 자체의 문제라고 단정할 수는 없습니다. 다른 모드 사용 여부도 함께 알려 주세요.

## 제거와 설정 초기화

게임을 종료하고 `BepInEx/plugins`에서 `SephPlanner.Plugin.dll`과 `SephPlanner.Core.dll`을 삭제하면 플러그인이 제거됩니다. 다른 모드의 파일은 그대로 두세요.

설정도 초기화하려면 필요한 파일을 백업한 뒤 다음을 삭제합니다.

- `BepInEx/config/dev.nyabi.sephplanner.bridge.cfg`: 패널 표시·단축키 등
- `%LOCALAPPDATA%\SephPlanner`: 빌드 설정(`plugin-settings.json`), 카탈로그, 진단 파일 등

다른 모드를 사용한다면 BepInEx 로더는 제거하지 마세요.

## 사용 조건과 구성요소

SephPlanner는 개인적·비상업적 목적으로 무료로 사용할 수 있습니다. 재배포·수정 등은 배포 ZIP의 `LICENSE.txt`를 확인해 주세요. 다운로드를 안내할 때는 파일을 다시 올리는 대신 이 저장소의 Releases 링크를 공유해 주세요.

함께 배포되는 BepInEx와 Unity Doorstop은 각각의 라이선스를 따릅니다. ZIP의 `제3자-라이선스` 폴더에 라이선스 원문과 소스 위치가 포함되어 있습니다. 이 도구의 사용 조건을 게임이나 제3자 구성요소의 사용 조건으로 해석하지 마세요.

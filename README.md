세피리아(Sephiria)의 석판·아티팩트 배치를 계산하고 게임 화면에 보여 주는 비공식 도우미입니다. 제안된 배치를 손으로 따라 옮기거나 `F8`로 적용할 수 있으며, 상자·상점·세피라이트의 후보와 석판 합성, 인챈트 대상도 추천합니다.

TEAM HORAY와 제휴·후원·공식 승인 관계가 없는 무료 팬 제작 도구입니다. 소스와 배포본이 모두 이 저장소에 있으며 MIT 라이선스입니다.

**[안정 버전 다운로드](https://github.com/nyabi-gh/SephPlanner/releases/latest) · [전체 버전·변경 사항](https://github.com/nyabi-gh/SephPlanner/releases) · [오류 제보](https://github.com/nyabi-gh/SephPlanner/issues) · [문의](#문의)**

Windows용 Steam 세피리아에 설치하며, 게임은 별도로 필요합니다. 배포 ZIP에는 BepInEx 5.4.23.5(win_x64, Mono)가 포함되어 있습니다.

`Pre-release`가 붙은 시험 버전은 전체 버전 목록에서 확인할 수 있습니다. 설치할 파일은 각 릴리스의 `SephPlanner-v버전.zip`입니다.

## 설치

### 처음 설치하는 경우

1. 게임을 종료합니다.
2. [Releases](https://github.com/nyabi-gh/SephPlanner/releases)에서 `SephPlanner-v버전.zip`을 받습니다. GitHub가 표시하는 `Source code (zip)`은 설치 파일이 아닙니다.
3. 압축을 풀고 `SephPlanner` 안의 **`게임 폴더에 복사` 폴더를 엽니다.**
4. Steam에서 세피리아 우클릭 → **관리 → 로컬 파일 보기**로 게임 폴더를 엽니다.
5. `게임 폴더에 복사` **안의 내용물**을 게임 폴더에 복사합니다. 폴더 자체를 통째로 넣지 마세요.
6. 게임을 실행합니다. 첫 실행에는 데이터 준비가 필요하며, 탐험에 들어가면 게임 화면에 배치 도우미가 나타납니다. 별도 프로그램을 실행할 필요는 없습니다.

설치 후 주요 파일 위치는 다음과 같습니다.

```text
Sephiria/
├─ Sephiria.exe
├─ winhttp.dll
├─ doorstop_config.ini
└─ BepInEx/
   ├─ core/
   └─ plugins/
      ├─ SephPlanner.Plugin.dll
      └─ SephPlanner.Core.dll
```

ZIP에는 `설치안내.txt`, 사용 조건인 `LICENSE.txt`, 제3자 라이선스, 파일 확인용 `manifest.json`도 들어 있습니다. 게임 파일은 포함하지 않습니다.

### 이미 BepInEx를 사용하거나 이전 버전에서 업데이트하는 경우

**게임 안에서 업데이트할 수 있습니다.** 게임을 켜면 플러그인이 GitHub Releases 에 새 안정판이 있는지 한 번 확인하고, 있으면 창을 띄웁니다. `업데이트`를 누르면 ZIP을 받아 DLL 두 개를 바꾸고, 게임을 다시 시작하면 새 버전이 적용됩니다. `나중에`를 누르면 다음 실행 때 다시 묻습니다. 확인을 원하지 않으면 `F3`의 `시작할 때 업데이트 확인`을 끄세요. 이 확인은 GitHub 에 "최신 판이 무엇인지"를 묻는 것뿐이며 다른 정보를 보내지 않습니다. 시험 버전(`Pre-release`)은 이 길로 안내하지 않습니다.

손으로 하려면 게임을 종료하고 ZIP의 `게임 폴더에 복사/BepInEx/plugins`에 있는 **DLL 두 개를 모두**(`SephPlanner.Plugin.dll`, `SephPlanner.Core.dll`) 게임의 `BepInEx/plugins`에 덮어쓰세요.

다른 모드에 사용하는 BepInEx 로더는 그대로 유지합니다. 이전 SephPlanner DLL을 다른 하위 폴더에 중복으로 남기지 마세요. 업데이트할 때 설정 폴더를 지울 필요는 없습니다. 필요한 카탈로그 갱신은 자동으로 진행되며, 준비가 끝나지 않거나 인식이 이상하면 게임 안에서 `F9`로 데이터를 다시 만들 수 있습니다.

## 단축키

| 기본 키 | 기능 |
|---|---|
| `F1` | 후보를 획득했을 때의 배치를 차례로 미리보기. 마지막 다음은 현재 가방 배치로 복귀 |
| `F2` | 빌드 창: 프리셋 코드, 콤보 우선순위, 강화 우선·양보·사용 유지·끄기 허용·레벨 제한·강화 대상·제한 해제 칸 고정 |
| `F3` | 설정 창: 표시, 크기, 위치, 불투명도, 추천, 갱신 주기, 단축키, 진단 전송, 업데이트 확인, 멀티 자동배치 |
| `F4` | 패널 숨기기·다시 표시. 숨겨도 계산은 계속 진행 |
| `F5` | 패널 불투명도 변경 |
| `F6` | 패널 이동 시작·종료. 이동 중 커서를 따라오며 다시 누르면 위치 저장 |
| `F7` | 패널 접기·펼치기 |
| `F8` | 현재 가방의 제안 배치 적용. 후보 미리보기 중에는 먼저 미리보기 종료 |
| `F9` | 게임 데이터 다시 생성 |
| `F10` | 진단·스냅샷·마지막 게시 계획의 재현 자료 저장. 동의한 경우 비공개 서버로 전송 |

화면에 표시되는 단축키가 위 표와 다르면 `F3`에서 변경된 키를 확인하세요. 이 문서의 `F1`~`F10`은 기본값이며, 바꾸는 방법은 [자세한 사용법](docs/USAGE.md#단축키-변경)에 있습니다. 빌드·설정 창은 마우스로 조작할 수 있으며, 싱글플레이에서는 창을 연 동안 게임 시간이 멈춥니다.

**게임패드**로 놀고 있다면 지도가 닫혀 있고 가방·상자 같은 게임 창이 떠 있는 동안 `View`(뒤로) 버튼으로 SephPlanner 창이 열립니다. 창 안은 스틱과 `A`로 조작하고 `B`(취소)로 닫으며, `바로 실행` 탭에 자동 배치·후보 미리보기·접기·숨기기가 버튼으로 있습니다. 패드에는 게임이 쓰지 않는 버튼이 없어 단축키를 따로 지정하지는 못합니다 - [게임패드로 쓰기](docs/USAGE.md#게임패드로-쓰기)에 자세한 것과 Steam Input 을 쓰는 길이 있습니다.

## 기본 사용법

탐험 중 현재 가방의 점수와 제안 배치의 점수를 보여 줍니다. 펼친 화면에는 배치 격자와 이동 안내가 나오며, 금색 테두리는 달라지는 자리를 뜻합니다. 칸이나 후보에 커서를 올리면 효과·레벨·추천 근거를 볼 수 있습니다.

상자·상점 등에서 선택지가 보이면 후보 추천이 나타납니다. 상점에서 사파이어로 보충한 칸의 물건도 함께 읽습니다. 후보 추천이 켜져 있으면 선택지가 나타나거나 합작 NPC의 석판 합성 창, 인챈트 제단의 아티팩트 선택 창을 열 때 패널도 자동으로 펼쳐집니다. 합작 추천을 보려고 상인에게 먼저 말을 걸 필요는 없습니다. 가까이 있다는 이유만으로 닫힌 상자의 내용을 보여 주지는 않습니다.

해골의 시작 아이템인 저주처럼 합성할 수 없는 석판은 합성 추천에서 제외합니다. 배치와 효과는 계속 계산합니다.

배치를 적용하는 길은 세 가지입니다.

- **수동 배치:** 이동 안내를 위에서부터 따라갑니다. `↔ 교환`은 두 칸을 드래그로 맞바꾸라는 뜻이며 가방이 꽉 차 있어도 가능합니다. 회전은 최종 자리에서 안내합니다.
- **자동 배치:** `F8`로 현재 가방의 제안을 적용합니다. 게임 상태와 계산 결과를 검증하며, 상태가 달라졌거나 검증에 실패하면 실행하지 않습니다.
- **후보 미리보기:** 아직 획득하지 않은 아이템까지 포함한 예상 배치입니다. 점수에 `미리보기`가 표시되며, `F8`을 누르면 현재 가방 배치로 돌아옵니다. 돌아온 배치를 확인한 뒤 다시 눌러야 적용됩니다. 후보를 자동으로 구매하거나 획득하지는 않습니다.

점수는 배치를 비교하기 위한 도구 자체의 평가값입니다. 게임의 공식 전투력 수치가 아니며, 탐색 결과가 수학적으로 가장 좋은 배치임을 보장하지 않습니다. 추천에는 능력치 기반 평가와 희귀도에 따른 추정이 함께 쓰이므로, 고유 효과와 원하는 플레이 방식도 함께 판단해 주세요.

현재 사용 중인 아티팩트와 지원 연결은 기본적으로 보호하며, 효과 점수가 낮다는 이유만으로 사용 중인 효과를 끄지는 않습니다. 어떤 배치를 왜 고르는지, 빌드를 어떻게 지정하는지는 **[자세한 사용법](docs/USAGE.md)**에 있습니다.

## 문제가 있을 때

| 증상 | 확인할 사항 |
|---|---|
| 패널이 보이지 않음 | 탐험에 들어갔는지, `F4`로 숨긴 상태인지, `F3`의 화면 표시가 켜져 있는지 확인합니다. 설치 경로와 DLL 두 개도 확인하세요. |
| 첫 실행에 데이터 준비 중 | 준비가 끝날 때까지 기다립니다. 계속 진행되지 않으면 아래 안내에 따라 제보하세요. |
| 패치 후 인식·계산 이상 | `F9`로 데이터를 다시 만들고, 문제가 남으면 `F10`으로 상태를 저장합니다. |
| 게임 상태와 계산 결과 불일치 | 해당 안내는 자동배치 잠금 사유입니다. `F10`으로 상태를 저장하고 화면의 경고와 함께 알려 주세요. |
| 최신 계획 계산 중·계산이 오래 걸림 | 계산이 끝난 뒤 다시 시도합니다. 오래 걸리거나 계속 반복되면 `F10`으로 상태를 저장하고, 대략적인 대기 시간과 기다렸을 때 결과가 나오는지를 로그·화면 안내와 함께 알려 주세요. |
| 서버 반영 불확실·재접속 필요 | 방에 재접속합니다. 단순히 키를 반복해서 눌러 잠금을 풀 수는 없습니다. |
| 활성 보호·사용 유지 배치를 찾지 못함 | 지정한 아이템과 화면에 표시된 이유를 확인합니다. 활성 칸·배치 조건·연동 무기 등을 확인하고, 모래시계라면 오른쪽에 사용 가능한 마법을 연결할 수 있는지도 확인하세요. |
| 아티팩트가 음수 칸으로 이동하거나 지원 연결이 끊김 | 해당 아이템의 [`끄기 허용`·`사용 유지`](docs/USAGE.md#빌드-지정-f2) 설정을 확인합니다. 문제가 남으면 `F10`으로 상태를 저장하고 기대한 배치와 실제 배치를 함께 알려 주세요. |
| 인챈트 창에서 추천이 보이지 않음 | `F3`의 `획득·합성·인챈트·제거 추천`을 켰는지 확인합니다. 제단에서 멀면 아직 계산하지 않으며, 가까이 가면 계산합니다. 인챈트가 이미 상한에 닿았거나 올려도 효과에 반영되지 않는 가방에서는 권할 대상이 없으며, 그 이유를 표시합니다. |
| 합작 NPC에서 추천이 보이지 않음 | `F3`의 `획득·합성·인챈트·제거 추천`을 켰는지, `F4`로 숨긴 상태인지, 합성기를 이미 사용했는지 확인합니다. `F7`로 펼쳐 확인할 수 있으며, 합칠 수 있는 조합이 없으면 이유를 표시합니다. |
| 단축키를 눌러도 반응이 없음 | `F3`의 단축키 탭에서 지정·해제·충돌 표시를 확인합니다. 설정 창 키까지 해제했다면 [설정 파일 복원 방법](docs/USAGE.md#단축키-변경)을 사용하세요. |
| 설정 저장 실패 | 이번 실행에서는 지정이 유지되지만 다음 실행에 남지 않을 수 있습니다. 로그의 저장 오류를 확인해 주세요. |
| 업데이트 실패 | 창에 표시된 이유를 확인합니다. 지금 버전은 그대로 남으며, [Releases](https://github.com/nyabi-gh/SephPlanner/releases/latest)에서 받아 손으로 덮어써도 됩니다. 새 버전이 있는데 창이 뜨지 않으면 `F3`의 `시작할 때 업데이트 확인`과 로그의 "업데이트 확인 실패"를 확인하세요. |

첫 실행에서 동의하면 감지한 오류의 진단 자료를 비공개 서버로 자동 전송합니다. `F3`의 `오류 진단 자동 전송`에서 언제든 철회할 수 있습니다. 직접 증상을 설명해 제보할 때는 문제가 발생한 상태에서 `F10`을 누르고, 표시되는 **제보 번호**와 함께 [Issues](https://github.com/nyabi-gh/SephPlanner/issues)에 알려 주세요. **진단 원본과 `.replay`에는 게임 데이터가 포함되므로 공개 Issues에 첨부하지 마세요.** 무엇이 수집되고 무엇을 함께 적어야 하는지는 [제보에 필요한 정보](docs/USAGE.md#제보에-필요한-정보)에 있습니다.

## 멀티플레이

멀티 자동배치는 **기본적으로 꺼져 있는 실험 기능**입니다. 읽기와 추천은 사용할 수 있으며, 함께 플레이하는 사람들의 동의를 받은 뒤 `F3`의 `멀티 자동 배치(실험)`에서 적용 기능을 켤 수 있습니다.

켜면 방을 연 사람과 참가한 사람 모두 사용할 수 있습니다. 참가자는 서버 반영을 한 걸음씩 확인하므로 시간이 걸릴 수 있습니다. 적용 중에는 가방을 직접 조작하지 말고 완료 안내를 기다려 주세요.

**서버 반영이 불확실하다는 경고가 나오면 추가 이동과 되돌리기를 중단하고 자동배치가 잠깁니다.** 앞선 명령이 늦게 도착할 수 있으므로, 안내대로 방에 재접속한 뒤 다시 사용하세요.

## 다른 모드와 함께 사용할 때

기존 BepInEx 환경에서는 SephPlanner의 DLL 두 개만 추가·교체하세요. 모든 모드 조합을 검증한 것은 아니므로 인벤토리·석판 효과·게임 입력을 바꾸는 모드를 함께 사용한다면 동작을 확인해야 합니다. 단축키가 겹치면 `F3`에서 변경하고, 문제가 생기면 사용 중인 다른 모드의 이름과 버전도 함께 제보해 주세요.

## 제거와 설정 초기화

게임을 종료하고 `BepInEx/plugins`에서 `SephPlanner.Plugin.dll`과 `SephPlanner.Core.dll`을 삭제하면 플러그인이 제거됩니다. 다른 모드의 파일은 그대로 두세요.

설정도 초기화하려면 필요한 파일을 백업한 뒤 다음을 삭제합니다.

- `BepInEx/config/dev.nyabi.sephplanner.bridge.cfg`: 패널 표시·단축키 등
- `%LOCALAPPDATA%\SephPlanner`: 빌드 설정(`plugin-settings.json`), 카탈로그, 진단 파일 등

다른 모드를 사용한다면 BepInEx 로더는 제거하지 마세요.

## 사용 조건과 구성요소

모드 사용은 본인 책임이며, TEAM HORAY는 공식 모드 지원을 제공하지 않습니다. 모드로 생긴 문제는 개발사의 지원 대상이 아니므로 중요한 세이브는 미리 백업해 두세요.

SephPlanner는 MIT 라이선스입니다. 쓰고 고치고 다시 배포하는 것이 모두 자유이며, 저작권 표시만 함께 남겨 주시면 됩니다. **만드는 쪽은 비영리를 지킵니다** — 광고·후원·구독 어느 것도 붙이지 않습니다. 개발사의 모드 정책이 상업적 목적의 모드를 제재 사유로 두고 있어서이며, 포크하실 때도 그 점을 보아 주세요.

다운로드를 안내할 때는 파일을 다시 올리는 대신 이 저장소의 Releases 링크를 공유해 주세요. 조건이 아니라 부탁입니다 — 옛 버전이 돌아다니면 이미 고친 문제로 제보가 옵니다.

함께 배포되는 BepInEx와 Unity Doorstop은 각각의 라이선스를 따릅니다. ZIP의 `제3자-라이선스` 폴더에 라이선스 원문과 소스 위치가 포함되어 있습니다. 이 도구의 사용 조건을 게임이나 제3자 구성요소의 사용 조건으로 해석하지 마세요.

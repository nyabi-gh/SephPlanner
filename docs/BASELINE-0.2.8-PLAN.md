# 0.2.8 기준 패치 계획

2026-09-10. 사용자가 0.2.8을 기준으로 이후 패치를 진행하기로 결정했다.
기준 태그는 `v0.2.8`, 커밋은 `3c1846f`다. 작업 브랜치는 `codex/0.2.8-patches`다.
기존 작업 공간의 0.3.2 및 미커밋 사용성 개편은 그대로 보존했다.

## 방향

0.2.8의 강화 우선·양보와 콤보 추천 기준, F2 두 탭과 점수 표시를 기준으로 한다.
이 점수는 실제 DPS가 아니며 기존 능력치 환산과 추정값이다. 알려진 효과 누락까지 해결됐다는
뜻은 아니다. 이후 기능은 필요한 문제를 재현하고 작은 패치로 하나씩 검증한 뒤 가져온다.

## 첫 패치

- 합작 창을 열거나 닫을 때 새 계획이 없어도 HUD 추천 목록을 갱신한다.
  `3c5069f`의 화면 갱신 수정과 회귀 테스트를 가져왔다. DPS 표시 변경은 가져오지 않았다.
- 0.3.x 및 실험 빌드의 전용 설정은 파일에서 보존하지만 계산에 반영하지 않는다.
  강화 우선·콤보 등 공통 설정은 계속 사용한다. 빌드 초기화는 이 버전이 지원하는 설정만 지운다.
  이후 버전으로 돌아가면 보존된 전용 설정이 다시 적용될 수 있다.
- 최소 강화, DPS 추천·상세 설정, 미계산 효과 변경 승인, 방향 설정은 포함하지 않는다.
  사용 유지·끄기 허용을 포함한 0.2.8 기존 조작도 우선 유지한다. 이름과 조작 개편은 실기 피드백 후 별도 패치한다.
- 첫 테스트 빌드는 0.2.8을 사용했고, 배포 준비에서 0.3.3으로 올렸다.

설정 보존은 기존 Json.NET의 [JsonExtensionData 공식 문서](https://www.newtonsoft.com/json/help/html/SerializationAttributes.htm)를
확인하여 구현했다. 패키지·게임 DLL 참조는 기준 버전 그대로 유지하고 빌드로 검증한다.

## 검증과 다음 순서

1. 전체 기존 테스트, 추가 회귀 테스트, 포맷, 진단 도구와 게임 DLL 참조 플러그인 빌드를 검사한다.
2. 0.2.8 기준 DLL로 실기 비교한다. 강화 우선 지정 전후, F2 두 탭, 합작 창 갱신, F8을 확인한다.
3. 발리송은 별도 패치로 다룬다. 게임 DLL에서 확인한 거리 조건과 WIDE 범위 확대를 근거로
   기존 평가에서의 수집·환산 누락을 조사한다. DPS 전용 구현을 그대로 가져오지 않는다.
4. 다른 제보도 이 기준 버전에서 재현한 뒤 필요한 수정만 가져온다. 종합 평가 모드나 새 설정 묶음을 다시 추가하지 않는다.

2026-09-10 사용자 요청으로 게임 설치 DLL 두 개를 이 기준 패치 빌드로 교체했다.
설치 파일의 SHA-256이 빌드와 일치하고 플러그인 어셈블리 버전은 0.2.8.0임을 확인했다.
교체 전 DLL은 원래 작업 공간의 `artifacts/game-backups/20260910-211109-before-028/`에 보관했다.
후속 패치 카탈로그는 형식 20으로 다시 수집되며 0.3.x F10 재현은 이 버전에서 지원하지 않는다.
기존 진단 파일을 지우거나 새 버전 입력을 구형 형식으로 가장하여 읽지 않는다.

## 결과

`scripts/check.ps1` 통과. 테스트 562개 통과, 실패·건너뜀 없음. 포맷·진단 도구·플러그인 Release
빌드도 통과했다. 새 코드 경고는 없고 NuGet 서버 연결 실패로 취약성 자료 조회 경고 NU1900이 남았다.
게임 화면·F8 실기는 아직 검증하지 않았다. 검사 로그는 `artifacts/baseline-check/check-baseline.log`에 보관한다.
테스트의 Json.NET은 잠금 파일 기준 13.0.3, 게임 참조 어셈블리는 13.0.0.0이다.
첫 패치 당시 `src/SephPlanner.Core`는 기준 태그 그대로였다. 아래 후속 패치에서는 공통 오류와 천칭 방향 보호를 수정했다.

## 릴리즈 수정 재검토

[0.3.0·0.3.1 선별 결과](RELEASE-BACKPORT-REVIEW.md)에 친타마니 지원 확인과 추가 이식 항목을 기록했다.
첫 패치만으로 이후 버전의 모든 공통 버그 수정을 가져온 것은 아니다. 다음은 제외·교체 제한과
마음의 짐 보호, F10 지문, 합성 음수 표시 순서로 진행한다.

## 후속 패치 구현

제외·교체 제한, 마음의 짐 기본 활성 보호, F10 수치 지문, 합성 부호를 수정했다.
사용자 선택에 따라 천칭은 현재 쪽을 유지하도록 탐색·후보 추천·캐시·자동 적용에 연결했다.
카탈로그 20과 재현 9를 사용하며 구형 재현 1·카탈로그 15도 검증 후 읽는다.
새 형식 번호는 기존 0.3.x 및 실험 형식과 충돌하지 않게 정했다. 제품 버전은 배포 준비에서 0.3.3으로 올렸다.
게임 DLL의 천칭 XIdx <= 2 규칙을 직접 확인했고 툴팁에도 조작 방법을 알린다.
최종 `scripts/check.ps1` 통과: 테스트 572개, 실패·건너뜀 없음. 포맷·진단 도구·플러그인 빌드도
통과했다. 실제 게임 Mono로 만든 형식 1과 9 자료를 .NET 테스트에서 재생하고 변조 차단을 확인했다.
카탈로그 수집·게임 화면·F8의 실기는 아직 검증하지 않았다. NuGet 연결 실패로 취약성 자료 조회 경고는 남았다.
로그는 `artifacts/baseline-check/check-backport-final.log`다.
2026-09-10 게임 DLL 두 개를 이 빌드로 교체하고 SHA-256 일치를 확인했다.
교체 전 DLL은 원래 작업 공간의 `artifacts/game-backups/20260910-212642-before-backports/`에 보관했다.

## 0.3.3 배포 준비

사용자 요청으로 버전을 0.3.3으로 올리고 프리릴리즈 드래프트를 준비한다.
소스는 비공개 저장소의 `codex/0.2.8-patches` 브랜치에 보존하며 공개 저장소에는 패키지만 올린다.

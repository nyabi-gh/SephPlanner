# DPS 전환 재검토

검토 대상은 `3c1846f`에서 `7e8644e`까지의 DPS 전환 55개 파일과 연결된 기존 코드다. 계산기·카탈로그 수집·설정·배치 탐색·획득/합성/제외 추천·비동기 게시·F2/HUD·F8 검증·F10 재현·진단 경로를 다시 추적했다. 아래 결함을 수정했으며 실제 게임의 피해 정확도와 화면 동작은 아직 검증하지 않았다.

| P2 | 0.1초 간격의 1초 전투와 0.2초 간격의 2초 전투에서 종료 시점의 공격까지 세어 10회가 11회가 됐다. | 무기·시전·전체 마법 대기·자동 발동·재충전에 보상 합산을 적용했다. 전투 범위는 시작 포함, 종료 제외다. |

| P2 | 새 전투 스냅샷이 소지금을 중복 수집하고 전체를 배치 입력 지문에 넣었다. DPS 식은 그 필드를 쓰지 않아도 동전 습득이 재계산을 요청했다. | 런타임은 기존 `RunState.Gold`만 수집한다. 구매 가능 여부 변경은 계속 추천을 갱신하며 실제 능력치가 바뀌면 전투 지문도 바뀐다. 기존 재현 파일의 입력 호환을 위해 옛 필드 정의는 보존했다. |

| P2 | 무기 식이 비어 있고 속성이 일반·혼돈이면 존재하지 않는 능력치를 읽어 0이 됐다. 알 수 없는 식과 접미부가 있는 최고/최저/전체 평균 식도 게임 분기와 달랐다. | `WeaponSimple.GetRelatedStatMultiplier`의 기본 배수 1과 식 분기를 반영한다. 실제 해당 프리팹의 종류·빈도는 이번 검토에서 측정하지 않았다. |

전투 조건의 목록이 `null`이거나 무기 순서에 마법·자동 공격 값이 들어간 잘못된 입력도 명시적인 설정 오류로 거부한다. 정상 설정의 기본값·추천 정책·제품 버전·의존성은 바꾸지 않았다.

## 근거와 검사

설치된 게임 1.0.30의 `Sephiria_Data/Managed/Assembly-CSharp.dll`을 사용했다. SHA-256은 `C3939A7D431F1362DACA655938480569E11F501F7D0820A989873765555A7C39`이며 로컬 디컴파일의 `WeaponSimple.GetRelatedStatMultiplier`에서 무기 식을 대조했다. 게임 어셈블리·디컴파일·카탈로그는 배포하지 않는다.

추가 회귀 검사 27개를 포함해 `scripts/check.ps1`에서 테스트 645개가 통과했다. 실패·건너뜀은 없고 잠금 파일 복원, 포맷, DataTool·Plugin Release 빌드도 통과했다. 빌드 경고·오류는 0개다. 로컬 로그는 `artifacts/dps-review-check-20260910.log`다.

검사에는 소수 공격·전체 마법 대기·충전·자동 발동의 종료 경계, 적중 후 발동 횟수, 공유 마나 회복의 계산 중단과 무관한 사건 삽입 전후 자원 일치, 콤보 단계를 잃는 제외 추천, 합성 내역 전달, 같은 DPS에서 추천 재현 내용의 차이, 구매 가능 여부와 배치 지문 분리를 포함했다. 기존 보호·위치·연결·설정 저장·전체 열거 비교·재현 검사도 유지했다.

## 재검토 당시 남은 확인 범위

아래는 재검토 완료 당시의 상태다. 이후 설정 전체를 쓰는 반복 배치 검증, 가변·혼돈·복합 속성 판정, F2 갱신 비용 기록을 [후속 작업](DPS-FOLLOWUP-2026-09-10.md)에서 보완했다.

- 새 카탈로그 형식 16을 실제 게임에서 다시 수집하고 F2, F8 반복 적용, F10 저장·재생을 확인해야 한다. 현재 로컬에 있던 카탈로그는 형식 15이며 새 어댑터의 실행 중 수집 성공을 입증하지 못한다.
- 실제 무기별 모션·마나 소모·소환물·상태 이상·추가 발동 등 기존 미지원 범위는 그대로다. 이번 검사 통과를 실제 DPS 오차율이나 전역 최적 배치의 보장으로 해석하지 않는다.
- 구형 `--churn`은 설정 전체와 게임의 F8 적용 검증을 복원하지 않는 별도 진단 도구다. 이 기존 한계는 `REPRODUCTION.md`에 명시했다. 전투 전환 결과를 같은 입력으로 비교하는 경로는 `.replay`다.
- F2 갱신·소지금 재계산 수정의 실전 프레임 비용은 측정하지 않았다. 성능 개선 수치를 주장하지 않는다.

게임 실행·조작 없이 확인할 수 있는 코드와 로컬 검사 범위의 결함을 수정한 결과이며 모든 버그가 없다는 보증은 아니다.

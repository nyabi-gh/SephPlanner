# 북향의 침·합작 추천 제보 점검

## 확인 범위

북향의 금빛 침(1289), 북향의 푸른 침(1290)을 모두 확인했다. 게임 1.0.30의 설치 DLL에서 `Charm_UpCharmDamage`, `Charm_SummonGreenBat`, `TabletMix`, `UI_TabletMixPanel`을 읽고 현재 로컬 카탈로그와 대조했다. 디컴파일 원문과 게임 카탈로그는 저장소에 추가하지 않는다.

제보자의 당시 F10 자료는 확보하지 못했다. 로컬 진단 스냅샷 10개에는 북향 두 종류가 없었다. 따라서 아래 재현은 게임에서 확인한 규칙과 별도로 구성한 가방으로 검증한 것이며 제보 당시 가방의 재생 결과는 아니다.

## 북향의 침

게임은 침 바로 위의 공격 가능한 아티팩트에 피해 보너스를 주고, 그 대상의 콤보를 침에 부여한다. 침이 이어져 있으면 마지막 대상을 따라간다. 행성 계열은 공격 가능한 아티팩트이며 석판은 침의 대상이 아니다. 금빛·푸른 침 모두 현재 카탈로그에서 같은 방향과 대상 판정을 사용한다. 대상의 희귀도에 따른 추가 보너스도 있어 행성 외의 아티팩트가 유효한 대상이 되는 것 자체는 게임 규칙 위반이 아니다.

확인된 버그는 F2 콤보 선택을 배치에 반영하는 `PriorityComboPlacement.Applies`가 열쇠와 하얀 종이만 대상으로 삼았다는 점이다. 북향은 콤보를 물려받는 계산에는 포함되지만 지정 콤보를 먼저 만족시키는 비교와 추가 탐색에서 빠져 있었다. ‘행성’을 골라도 다른 콤보의 다음 발동 단계나 기존 자리 선호가 이길 수 있었다.

게임에서 확인한 두 침의 표와 공격 가능한 행성·다른 공격 아티팩트를 사용해 재현했다. 수정 전에는 행성을 선택하고도 다른 아티팩트 아래를 유지했다. 공통 자리 의존 콤보 판정에 포함하고, 대상과 침을 함께 배치하는 후보를 추가해 수정했다. 만족할 수 없는 지정은 이유를 표시한다. 아이템 ID에 따른 처리 예외는 넣지 않았다.

회귀 검사는 두 침 각각에 대해 이미 행성의 마지막 콤보 단계를 넘은 경우, 공격 불가능한 대상, 석판 아래에서 시작하는 침 두 개의 연결, 후보 추천 ON/OFF를 포함한다. 기존 활성·사용 유지·고정 조건과 같은 배치 비교를 사용한다.

행성을 의도하면 F2의 콤보 목록에서 ‘행성’을 선택한다. 위치를 따로 고정해야 하는 기능은 아니다. 콤보를 지정하지 않으면 기존 가치 기준으로 대상이 선택된다. 현재 피해 효율 평가는 추정이며 실제 전투 DPS로 가장 강한 행성을 고르는 모델은 아니다. 제보의 ‘석판 바로 아래’ 배치가 왜 선택됐는지는 해당 F10의 재현 자료가 있어야 판정할 수 있다. 이번 검사에서 유효한 연결이 가능한 석판 방해 배치는 정상 연결로 복구됐다.

## 합작 NPC

게임의 합작 NPC는 `TabletMix.HandleInteractive`에서 `UI_TabletMixPanel.Open(this)`를 호출한다. 상점 재고 창과 다른 UI다. 기존 코드는 층의 합성기와 추천 조합을 읽고도, HUD 자동 펼침은 `plan.Offers`의 구매·획득 후보만 확인했다. 합성 추천은 접힌 상세 영역에 있어서 상인에게 말 걸어 구매 후보가 생긴 뒤에야 함께 보였다.

실제 합성 창의 `IsOpened`를 자동 펼침 상태에 반영했다. 상인→합작 NPC 전환, 합작 단독 열기·닫기·다시 열기를 처리하고, 같은 창에서 사용자가 직접 접은 상태는 매 프레임 덮어쓰지 않는다. 추천할 수 있는 조합이 없거나 합성기를 읽는 중인 경우에도 해당 상태를 표시한다. 추천을 끈 설정은 유지한다.

수정 전에는 합작 NPC에서 F7로 직접 상세 화면을 펼치면 이미 계산된 합성 추천을 볼 수 있었다. 수정 후에는 합성 창을 열 때 자동으로 펼쳐진다. 실제 맵과 상점 합작 NPC에서의 화면 확인은 게임 재시작 후 별도로 필요하다.

## 검증 결과

`scripts/check.ps1`에서 전체 559개 테스트, 포맷, 진단 도구와 플러그인 Release 빌드가 통과했다. 경고·오류는 없었다. 북향과 합성 창 상태 전환에 신규 회귀 검사 12개를 추가했으며 기존 테스트는 변경하지 않았다. 게임이 실행 중이므로 수정 DLL은 아직 설치하지 않았다.

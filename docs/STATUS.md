# 현재 구현과 검증 상태

2026-09-11. `v0.2.8`을 기준으로 필요한 수정만 가져온 결과가 `main`에 있다. 제품 버전은 0.3.3,
카탈로그 형식은 20이며 DPS 중심 추천과 0.3.x 설정 화면은 포함하지 않는다.
0.3.3은 Pre-release로 배포됐고 실기 검증은 아직이다. 릴리스 페이지의 Latest는 여전히 0.2.8이다.
[기준과 패치 계획](BASELINE-0.2.8-PLAN.md)에 범위와 검증 결과를 기록한다.
아래 표는 0.2.8의 구현 범위이며 이후 버전의 감사 문서와 혼동하지 않는다.

## 구현 범위

| 영역 | 현재 지원 | 남은 범위 |
|---|---|---|
| 석판·활성 | 질의·회전·인챈트·각인·친타마니 칸 효과와 현재 상태 대조 | 합성 인스턴스 질의의 게임 원본 전수 대조, 새 활성 조건 진단 |
| 배치 | 기본 활성·지원 연결 보호, 석판 이동·회전·교환 후 재배정, 같은 효과에서 감점 빈칸 정리 | 제한된 탐색이며 전역 최적을 보장하지 않음 |
| 사용자 지정 | 강화·양보는 이득에만 가중치, 끄기 허용 분리, 사용 유지·고정·열쇠와 종이의 콤보 우선 | 최소 레벨·좌표/회전 고정·프로필 |
| 마법 지원·침 | 모래시계·별조각의 방향·대상, 침의 사슬·공격 가능성·잔여 보너스, 확인된 마법 치명타·마나 회복의 주력 선호 | 실제 마나 소비·시전 빈도·대상 DPS와 다른 비용 변경 효과 |
| 수량·행 | 벨트·비늘·열쇠의 추가 능력치 환산 | 전체 증폭·전환·전투 효율 |
| 동적 카테고리 | 열쇠·침, 종이의 일치 조건과 최근 관측값 | 종이 중첩의 실제 이동·갱신 순서 재현 |
| 특수 콤보 | 게임 공통 데이터의 발동 단계 수집과 실패 처리 | 새 프리팹 실기 대조, 콤보별 전투 가치 |
| 망원경·휘장 | 이웃·행에 따른 추정 가치 | 대상의 실제 사용 가능 상태·타입·강화 중첩과 효과량 |
| 능력치 전환 | 진단 자료와 별도 상태 재현 실험 | 실제 기여·콜백 어댑터와 자동 배치 통합 |
| 자동 적용 | 상태·지문·회전·최종 위치 검사, 안전한 범위의 되돌리기, 불확실한 서버 쓰기 차단 | 최신 DLL의 참가자 회전·실패·복구 실기 |
| 재현 | F10의 게시 계획 입력·설정·카탈로그·직전 목표 보존과 독립 재생 | 인게임 저장·재생 및 저장 비용 실측 |

F2 콤보는 추천 OFF에서도 배치에 영향을 준다. `끄기 허용` 변경도 재계산과 오래된 계획의
적용 차단에 반영한다. 획득·제거·합성 추천은 원래 가방의 활성 보호를 함께 적용한다.

## 정확도와 측정

게임의 레벨 계산이 일치한다는 것, 모델의 점수가 재현된다는 것, 전투에서 좋은 선택이라는
것은 서로 다른 검증이다. `FullHP`는 배치 계산에서 만족으로 취급하며 미지 조건은 현재
`None`으로 해석한다. 레어도·공통 콤보 가치·일부 연결 효과는 추정이 남아 있다.

저장 형식 9 카탈로그의 과거 분류는 정적 표 105종, 부분 표와 추정 52종, 추정 142종이다.
이 숫자는 현재 전투 효과 지원율이 아니다. 새 형식 20으로 모든 프리팹을 다시 수집한 결과는
아직 없으며, 수동 가치 자료는 빈 배열이다. 과거 성능 수치도 최신 빌드의 측정값으로 재사용하지 않는다.

## 다음 작업과 완료 기준

1. 배포된 0.3.3 DLL과 형식 20 카탈로그를 게임에서 대조한다. 활성 보호·감점 칸 정리·콤보·연결·수량 효과와
   F10 재현을 확인하고 사용한 빌드·카탈로그·싱글/호스트/참가자를 기록한다. 이 확인이 Latest 승격의 조건이다.
2. 실제 교환·효과 콜백 전후를 수집한다. 출처별 능력치의 제거·재적용과 호출 순서를 진단
   모델로 재현하고 같은 입력·결과가 확인된 범위만 자동 배치에 연결한다.
3. 큰 가방·후보·연결 묶음이 있는 고정 사례에서 시간과 할당량을 측정한다. 그 결과로 탐색
   비용과 후보 제거 갈래의 편향을 개선할 순서를 정한다.

현재 `main`에서 `scripts/check.ps1`이 잠금 파일 기준 복원, 포맷 검사, 테스트 572개,
DataTool·Plugin Release 빌드까지 통과한다. 실패·건너뛴 테스트와 빌드 오류는 없다. 남은 경고
4개는 전부 `NU1900`으로, 취약성 조회 서버에 접근하지 못한 것이며 취약성 목록의 최신 여부는
확인하지 못했다. 전체 검사 로그는 로컬 `artifacts/check-ignore-reports.log`에 보관한다.

2026-09-11에 게임 폴더의 두 DLL을 배포된 0.3.3 zip의 것으로 맞추고 `manifest.json`의 SHA-256과
대조했다. 그 zip의 커밋은 태그 `v0.3.3`과 같고 태그 이후 `src`와 `tests`는 바뀌지 않았으므로,
지금 설치된 바이트가 곧 이 저장소의 현재 소스다. 그 위에서의 실기는 아직 하지 않았다.
위 검사는 자동 배치·멀티플레이·게임 내 대기 시간 검증을 대신하지 않는다.

## 공통 수정 이식

버리기 금지, 자체 활성 효과 없음 판정, 합성 음수 표시, F10 수치 지문 수정을 이식했다.
대립의 천칭은 보유 인스턴스마다 현재 좌우를 유지한다. 같은 쪽 안의 이동은 허용하며 사용자가
직접 반대쪽으로 옮기면 다음 계획부터 새 방향을 따른다. 아직 줍지 않은 천칭의 방향은 고정하지 않는다.
좌우 능력치의 실전 기여를 비교하는 기능은 아니다.
새 카탈로그 형식은 20, 재현 형식은 9다. 이미 사용된 0.3.x 형식 번호를 재사용하지 않는다.
형식 1·카탈로그 15의 구형 자료는 숫자 지문을 검증한 뒤 변경 전후 비교로 읽는다.
구형 카탈로그에는 새 판정 속성이 없으므로 당시 관측 범위 안에서 재생한다.

# 현재 구현과 검증 상태

2026-09-10 DPS 전환 개발 코드 기준이다. 제품 버전은 0.2.8이며 이번 변경은 미출시 작업이다. 카탈로그 형식은 16, 계획 재현 형식은 3이다. 날짜가 붙은 과거 감사·성능 문서는 당시 상태의 기록이며 현재 동작은 이 문서와 [예상 DPS 안내](DPS.md)를 따른다.

## 구현 범위

자동 배치, 획득·제외·합성 추천, 후보 미리보기는 배치 전체의 예상 DPS를 사용한다. 배정과 석판 후보 생성도 DPS 변화량을 기준으로 하며 희귀도·레벨 환산·F2 배수를 피해에 섞지 않는다. 전투 자료가 없는 과거 진단·테스트 입력만 이전 평가 경로를 유지한다.

F2에서 단일·다수 대상과 추가 대상 적중 비율, 시간·자원 프리셋, 공격 순서, 마법 사용·우선순위, 실측 간격 보정을 지정한다. 기본은 30초·단일 대상·자원 가득이다. 현재 활성·연결 보호는 기본으로 켜며 해제할 수 있다. 개별 사용 유지·고정은 유지하고 콤보 강제 우선·프리셋 즐겨찾기는 빌드 우선을 켰을 때만 순위를 앞선다.

| 영역 | 현재 지원 | 추정·미반영 |
|---|---|---|
| 배치 구조 | 기존 석판 질의·회전·인챈트·각인·활성 검증과 이동 적용 | 전역 최적을 보장하지 않는 제한된 탐색 |
| 능력치 | 알려진 출처 교체·제거, 증폭·원소 전환, 대시 피해, 수량·행·주변 레벨 | 주기적 전환·임시 버프·콜백 출처는 관측 잔여값 고정 |
| 공격 | 무기 프리팹, 볼트 마법, 볼루스파, 화염검 기본 발동 | 기타 고유 공격·소환물·상태 이상·무기 상태 분기 |
| 전투 조건 | 치명타·처형 기대값·공통 피해·대상 방어·저항·회피 | 실제 모션·이동·명중률·비행·적 체력·보호막 |
| 자원 | 마법의 공유 마나·비용·회복 지연·시전 시간·충전·순차 재충전 | 연속 회복 근사, 예약·추가 회복 발동·무기 마나·대시 충전 |
| 위치와 연결 | 영원의 식 좌우 전환, 침 사슬과 모래시계·별조각, 콤보 능력치 | 다른 위치 기반 발동·종이 중첩 갱신 순서 |
| 결과·재현 | 전체·초반·후반·빈 자원 시작 DPS·공격별 피해·누락·미지원 변경 내역, 전투 입력 지문과 F10 재현 | 새 DLL의 인게임 화면·피해·입력·멀티 실기 |

## 정확도와 검증

게임 DLL 1.0.30에서 확인한 규칙과 실행 중 프리팹 자료를 사용한다. 피해식을 계산하기 위해 게임 객체를 변경하지 않는다. 공격·시전 시간 기본 1초와 추가 대상 적중 기본 50%는 비교 시나리오 추정이다. 미지원 효과는 표시하면서 추천을 유지하되 관련 아이템 상태·주변·지원 연결·콤보 수량 변경의 자동 적용은 기본 제한한다. 별도 허용을 켜도 계산 오류와 기존 활성·레벨 검증은 통과하지 않는다. 제한은 파악한 관계에 대한 검사이며 모든 미지원 상호작용을 보장하지 않는다.

작은 배치의 전체 열거와 DPS 솔버 결과, 대시·속성 전환, 공유 마나·충전·치명타·설정 저장·재현을 검사했다. 성능은 합성 예제에서 측정했으며 실제 게임 내 성능이나 오차율은 아니다. 측정 조건·최종 검사와 설치 결과는 [작업 기록](DPS-IMPLEMENTATION.md)에 남긴다.

## 후속 실기 검증

새 DLL의 F2 전투·마법·누락 표시, F8 반복 적용과 F10 재현을 게임에서 확인해야 한다. 현재 허용 범위는 게임 종료 상태의 설치까지이며 게임 실행·조작은 수행하지 않는다. 실제 무기 모션과 관측 피해 대조, 얼음 무구·소환물·상태 이상·추가 발동 어댑터 확장은 후속 정확도 작업이다.

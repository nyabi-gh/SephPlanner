# 화면 표기 검수

2026-09-16. 붉은 이슬에 북향의 침이 연결되는 제보에서 시작했다. 게임 규칙·배치 우선순위와
화면의 짧은 이름을 대조하고, 무엇을 바꾸는 설정인지와 서로 충돌할 때 어느 지정이 앞서는지
설명했다. 배치 계산과 저장 설정의 의미는 바꾸지 않았다.

## 검수 범위와 수정

| 화면 | 문제 | 수정 |
| --- | --- | --- |
| 빌드 설정 | `대상`이 무엇을 지원하는지 알 수 없음 | `침·모래시계·별조각 우선`, 콤보 지정보다 앞선다는 설명 |
| 빌드 설정 | `고정`을 좌표 고정으로 오해 | `조건 무시 칸`, 배치 조건을 무시하는 칸을 요구한다고 설명 |
| 빌드 설정 | `레벨 제한`을 실제 레벨 상한으로 오해 | `목표 레벨`, 평가에만 적용하며 더 높은 레벨에 놓일 수 있다고 설명 |
| 빌드 설정 | 양보를 침 연결 금지·효과 끄기로 오해 | 강화칸 선호라는 의미와 콤보 지정이 앞서는 경우를 안내 |
| 빌드 설정 | `지우기`와 `빌드 초기화`의 범위 불명확 | `코드 해제`와 `빌드 지정 초기화`로 구분 |
| 빌드 설정 | 이름·수치·버튼이 한 줄에서 서로 밀어냄 | 이름과 버튼을 두 줄로 분리, 한 페이지 여섯 항목 |
| 설정 | `표시 설정`에 추천·전송·업데이트까지 섞임 | `일반 설정`, `바로 실행`, 기능 범위가 드러나는 항목 이름 |
| 설정 | 켜짐 상태와 켜는 동작의 표기가 혼재 | 선택값은 `꺼짐`·`켜짐`으로 통일 |
| HUD | 점수 두 개의 의미와 선택 이유가 불명확 | `현재 → 제안` 또는 `현재 → 획득 후`, 추정 점수 설명 |
| HUD | 긴 배치 이유를 고정 폭 4배 칸에서 잘라 표시 | 전용 문단으로 줄바꿈, 지원 대상 우선도 이유로 표시 |
| HUD | 설정 쪽지에 지원 대상·목표 레벨·끄기 허용 누락 | 각 설정의 의미와 적용 중인 상태를 설명 |
| HUD | 회전이 0~3으로 표시됨 | 실제 각도인 0~270°로 표시 |
| 경고 | 강화받는 아이템의 지정을 침 자신에서 해제하라는 듯한 안내 | 해제할 아이템과 현재 버튼 이름을 정확히 지칭 |
| 진단 | 메모 확인을 거치는데 `자동 전송`으로 설명 | 메모 창에서 보내기·전송 안 함을 선택하며 PC 저장은 남는다고 설명 |
| 업데이트 | 플레이어에게 DLL 교체 경로를 나열 | 새 버전 설치, 설정 유지, 재시작 시 적용되는 결과를 설명 |

사용 유지·끄기 허용·자동 배치·후보 미리보기처럼 의미가 이미 구체적인 이름은 유지했다.
UI와 사용법·설치 안내·현재 상태·인계의 이름을 맞췄다. 과거 릴리스 및 검토 문서는 당시 표기를 보존한다.

## 실제 동작과의 대조

게임 1.0.33의 `Assembly-CSharp.dll` SHA-256은
`c57a0daeab8e8d0af7066a344133eec4c57d8f303fd9e25da9410fbfc4cf1510`이다.
`Charm_UpCharmDamage.SearchCategory`는 사슬 끝의 공격 가능한 대상 카테고리를 복사한다.
`Charm_Reddew`는 그 대상이 될 수 있으며 피해 보너스도 적용된다.
`Charm_ReduceMPCost.SearchMagic`은 왼쪽 마법의 비용을 줄인다. 카탈로그에서 레이에 별조각(1069)에
대응하며, 플래너의 지원 대상 지정은 이 효과도 포함한다. 따라서 버튼에서 별조각을 빼면 안 된다.

제보의 원본은 0.4.2이고 양보 -3과 정밀 우선이 함께 켜져 있었다. 내장 카탈로그를 사용한 원본
재생은 0.4.2 소스와 당시 현재 코드에서 저장 결과와 차이가 없었다. 정밀만 해제하면 금빛 침은
볼트 3·이슬 2, 파이어 볼트를 지원 대상으로 지정하면 볼트 5가 됐다. 후자의 유효한 배치는 원래
설정에서도 일반 점수가 더 높지만 지정 콤보 만족 수에서 밀린다. 이번 제보는 콤보 우선순위로
설명되며, 앞서 작은 가방으로 찾은 양보 가중치의 부분 적용은 별도 계산 한계다.

원본 진단·게임 데이터·임시 재현 코드는 로컬 `reports/`에만 보관한다.

## 화면 배치와 확인 범위

빌드 창은 설정 창과 같은 기준 폭 38배를 사용한다. 픽셀 반올림 전 치수로 내부 여백을 제외하면
아티팩트 설정 줄에 35.3배 폭이 남으며, 모든 버튼과 간격의 합은 31.3배다. 이름은 별도 줄의 남는 폭을 쓴다.
점수와 배치 이유는 현재 HUD 폭으로 글 높이를 다시 재므로 좁게 접은 상태에서도 줄바꿈한다.
이는 코드의 배치 치수 검토이며 실제 글꼴로 렌더링한 화면 검사는 아니다.

게임은 실행 중이지 않았다. 실제 한글 글꼴·작은 화면·패드 초점 이동은 배포 전 확인이 필요하다.
설정 키·지문·배치 계산은 유지하며, 경고 문구를 검증하는 기존 테스트의 기대 문구만 변경했다.

`scripts/check.ps1`의 770개 테스트, 포맷 검사, 진단 도구와 게임 플러그인 빌드가 통과했다.
0.4.5 코드로도 붉은 이슬 제보 원본을 다시 재생했으며 저장된 결과와 차이는 0건이었다.

# 석판 개선 단계의 아티팩트 배치 보존

2026-09-17. 망원경 제보 `e006deee8fdb40e1b754333e913aca2d`를 조사했다.
수집 버전은 0.4.7, 게임 1.0.33이다. 게임 규칙과 가치 표는 바꾸지 않았다.

## 원인과 수정

석판 개선 단계는 방금 찾은 석판 배치에서 이동·회전 후보를 만들지만, 그와 함께 찾은
아티팩트 배치는 후보 평가에 전달하지 않았다. 아티팩트 배정은 이웃 정보 없이 다시 시작하므로
망원경처럼 주변 배치에 의존하는 효과에서 이미 찾은 관계를 잃을 수 있었다.
실험에서는 필요한 회전 후보가 평가 대상에 포함돼도 더 좋은 아티팩트 배정을 놓쳤다.

`ImproveTablets`가 현재 최선의 아티팩트 배치를 `RefineLayouts`에 전달한다.
기존 초기 배정과 해당 배치에서 이어가는 배정을 각각 평가하고, 기존 우선순위로 더 좋은 결과를
선택한다. 이어갈 배치의 점유·석판 효과·이웃·점수는 새 석판 후보 기준으로 다시 계산한다.
첫 재배정이 더 나빠지거나 같은 배치로 끝나도 출발 배치는 비교 대상으로 남는다.

석판과 충돌하거나, 항목이 빠지거나, 중복·격자 밖 좌표·이동 불가 아이템의 이동이 있으면
그 출발 배치를 사용하지 않는다. 해당 석판 후보는 기존 초기 배정으로 계속 평가한다.
입력 배치와 현재 위치·이전 계획의 선호는 변경하지 않는다.
탐색 후보 예산과 반복 상한은 유지하되, 유효한 출발 배치가 있는 후보는 배정 경로를 추가 평가한다.
자동배치 후 재계산을 추가하거나 특정 아이템·좌표에 예외를 넣지는 않았다.

## 검증

- 합성 입력으로 회귀 테스트 9개를 추가했다. 이웃 배정의 개선, 출발점 보존, 기존 결과와의
  비교, 입력 불변성, 충돌·누락·중복·알 수 없는 항목·격자 밖 좌표, 이동 불가 아이템을 검사한다.
- 첨부 자료의 `PreviousTargets.From/FromRotation`으로 이동 전 좌표를 구성하고 이전 계획
  앵커를 비운 동일한 문제를 비교했다. 기존 코드는 점수 190.29919985166, 주변 행성 6/7개에서
  끝났고 수정 후에는 한 번의 `Solve`에서 190.74058640628184, 7/7개가 됐다.
  이는 적용 전 전체 게임 상태의 완전 복원이 아니라 좌표를 통제한 원인 분리 실험이다.
- 개선된 배치를 현재·이전 목표 좌표에 반영해 세 번 더 풀었고, 매번 변경 0개와 같은 점수를
  확인했다. 실제 게임의 효과 재계산과 입력 조작을 검증한 것은 아니다.
- 기존 제보 15개와 이번 첨부의 일반 리플레이를 변경 전후 같은 내장 카탈로그로 실행했다.
  `ReplayResult`의 배치·점수·검증·추천 등 전체 결과는 16개 모두 동일했다.
  이번 첨부는 적용 후 상태라 기존 코드도 새로 탐색하면 개선안을 찾는다. 따라서 일반 재생의
  일치와 이동 전 좌표 실험의 개선은 서로 모순되지 않는다.
- `scripts/check.ps1`: 테스트 796개 통과, 실패·건너뜀 0. 포맷 검사와 진단 도구·플러그인
  빌드도 통과했다. NuGet 취약성 정보 서버 연결 실패 경고 `NU1900`이 있었다.

## 계산 비용과 범위

부분 복구, 리플레이의 탐색 생략 상태 보존은 이번 수정 범위에 포함하지 않는다.

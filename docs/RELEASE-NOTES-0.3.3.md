0.2.8의 추천 방식과 화면을 기준으로 필요한 오류 수정을 반영한 테스트 버전입니다. 실제 게임 화면과 자동 배치의 최종 실기 검증은 진행 중입니다.

### Changed

- 강화 우선·양보와 콤보를 기준으로 추천하고, F2를 기존 콤보·아티팩트 두 탭으로 되돌렸습니다.
- DPS 중심 추천과 전투 조건 설정은 이번 버전에 포함하지 않습니다. 이전 버전 전용 설정은 파일에 보존하지만 계산에는 적용하지 않습니다.
- 대립의 천칭은 자동 배치에서 현재 놓인 쪽을 유지합니다. 방향을 바꾸려면 직접 반대쪽으로 옮기세요.

### Fixed

- 버릴 수 없는 아티팩트를 제외하거나 새 아이템과 교체하라고 추천하던 문제를 수정했습니다.
- 마음의 짐처럼 자체 활성 효과가 없는 아이템이 유용한 활성 칸을 차지하던 문제를 수정했습니다. 주변 효과와 사용 유지·고정은 계속 고려합니다.
- 추천 화면이 이미 펼쳐진 상태에서 합작 창을 열거나 닫아도 합성 추천 목록이 갱신되도록 수정했습니다.
- 합성 추천에서 손해가 나는 값에 양수 부호가 붙던 표시를 수정했습니다.
- 게임에서 저장한 F10 자료가 숫자 표기 차이로 재생되지 않던 문제를 수정했습니다. 0.2.8 자료도 변경 전후 비교에 사용할 수 있습니다.

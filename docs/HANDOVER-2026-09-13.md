## 3. 다음 일감 — 저장소 합치기

라이선스는 MIT 로 바꿨고 문서도 합친 뒤 상태로 써 두었지만 **저장소는 아직 비공개이고 합치지
않았다.** 명령 다섯 줄과 정하지 않은 것 셋이 STATUS 의 **"저장소 공개와 합치기"** 절에 있다.

방향이 뒤집힌 이유만 기억하면 된다. **누적 다운로드 929 가 릴리스 저장소의 자산에 붙어 있어
옮길 수 없다.** 그래서 이름이 맞는 소스 저장소를 공개하는 대신, 소스를 릴리스 저장소로 옮기고
이름을 바꾼다. 이슈 0·포크 0·스타 1 이라 그 밖에 지킬 것이 없다.

**README 의 배지와 "이 저장소" 서술은 지금 앞서 있다** — 합치는 순간 맞는다. 고치지 말고 두라.

## 4. 알아 둘 것 둘

**CI 가 0.3.8 부터 이레 동안 빨갰다.** `.gitattributes` 가 `eol=lf` 인데 `.editorconfig` 가
줄바꿈을 말하지 않아, 윈도우의 `dotnet format` 이 자기가 다시 들여쓰는 줄에만 CRLF 를 썼다.
로컬 작업 트리는 초록, 커밋은 LF, LF 로 체크아웃하는 CI 는 영원히 빨강. `git status` 에는
아무것도 안 보인다. `end_of_line = lf` 한 줄로 닫혔다. **파일을 통째로 다시 쓰는 편집을 한 뒤
포맷 검사가 이상하면 여기부터 본다.**

**문서가 옮겨졌다.** 대문 `README.md` 는 이제 사용자용(옛 릴리스 저장소 README)이고, 개발 쪽은
[개발 문서](DEVELOPMENT.md)다 — 구조·빌드·진단 도구·배포 절차·화면 설계. `CHANGELOG.md` 는
`docs/` 로 갔다(`make-release.ps1` 도 거기서 읽는다). 겹치던 UI 설명은 버렸다.

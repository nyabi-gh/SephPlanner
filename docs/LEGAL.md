# 약관·저작권 검토

법률 자문이 아니라, 이 프로젝트를 설계할 때 근거로 삼은 사실 정리다.

## 적용되는 약관

세피리아 스팀 상점 페이지에는 별도 EULA나 서드파티 라이선스 링크가 없다. 따라서 기준이 되는
문서는 **Steam 구독자 약관(SSA)** 이다.

| 조항 | 내용 | 이 프로젝트와의 관계 |
|---|---|---|
| SSA §2.G | 사전 서면 동의 없는 리버스 엔지니어링·디컴파일·파생물 제작 금지 | 게임 어셈블리를 참조하는 BepInEx 플러그인이 여기에 걸릴 소지가 있다 |
| SSA §2.G | 사전 허락 없는 상업적 이용 금지 | 이 프로젝트를 비영리로 유지하는 이유 |
| SSA §4.B | 치트 제작·사용 금지 | 게임은 4인 온라인 코옵을 지원한다 |

## 이 프로젝트가 택한 완화 조치

1. **읽기 전용.** 플러그인은 게임 상태를 읽기만 하고 쓰지 않는다. 자동배치 결과를 게임에 되적용하는
   기능은 넣지 않았다. 코옵에서 다른 플레이어에게 영향을 주는 순간 SSA §4.B의 "치트" 해석 여지가
   생기기 때문이다.
2. **멀티 세션 감지.** 스냅샷에 `IsMultiplayer` 플래그가 있고, 오버레이는 멀티 세션에서 조언 표시만
   유지한다. 앞으로 쓰기 기능을 추가하더라도 이 플래그로 잠근다.
3. **게임 저작물 미배포.** 아이콘·스프라이트 등 에셋을 추출해 배포물에 넣지 않는다.
   - 석판/아티팩트의 **모양과 효과**는 사용자 PC에서 게임 실행 중에 덤프한다. `sharedassets` 리핑이
     필요 없다.
   - **이름과 설명 텍스트**는 `SephPlanner.DataTool`이 사용자 PC의 `StreamingAssets/Localization`에서
     추출한다. 결과물(`data/generated/`)은 `.gitignore` 대상이며 배포물에 포함하지 않는다.
   - 게임 DLL은 `<Private>false</Private>`로 참조만 하고 출력 폴더에 복사하지 않는다.
4. **비영리.** 광고·구독·후원 어느 것도 붙이지 않는다. 붙이는 순간 SSA §2.G의 상업적 이용에
   직접 부딪힌다.
5. **외부 위키 데이터 미사용.** 나무위키는 CC BY-NC-SA 2.0 KR이라 비영리·동일조건변경허락 조건이
   따라붙는다. 데이터를 게임에서 직접 뽑으면 이 조건에 얽히지 않는다.

## 남은 리스크와 해소 방법

가장 확실한 해소책은 **TEAM HORAY에 직접 확인받는 것**이다. 공식 디스코드나 문의 메일로
"인벤토리 상태를 읽기만 하는 비영리 오버레이를 만들어 커뮤니티에 무료 배포하려 한다"고 알리고
답을 받아 이 문서에 기록한다. 세피리아는 안티치트가 없고 이미 커뮤니티 모드가 여럿 돌아가고 있어
분위기 자체는 우호적이지만, 묵인은 허락이 아니다.

## 배포 시 지켜야 할 것

- 배포물에는 우리가 작성한 코드와 자산만 포함한다. 예외는 오버레이에 임베드한 Galmuri 폰트로,
  SIL OFL-1.1이라 재배포가 허용되며 라이선스 사본(`src/SephPlanner.Overlay/Fonts/LICENSE.txt`)을
  함께 배포한다.
- 설치 안내는 "BepInEx를 직접 설치하고 우리 플러그인 DLL을 넣으세요" 형태여야 한다.
  BepInEx나 게임 파일을 재배포하지 않는다.

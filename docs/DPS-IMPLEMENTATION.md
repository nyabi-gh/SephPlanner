## 확정한 동작

## 구현

출처별 능력치 교체·제거와 증폭·원소 전환, 무기·볼트·볼루스파·화염검의 일부 공격, 공유 마나·시전·충전 사건 계산을 연결했다. 탐색의 후보 추정과 최종 배치, 획득·제외·합성 추천과 미리보기까지 예상 DPS를 사용한다. F2 전투·마법·DPS 내역, 설정 저장, 전투 입력 지문, 카탈로그 16을 추가했다. 재현 형식은 처음 2에서 후속 정책·구간 비교·시간 보정을 담는 3으로 변경했다.

현재 기여를 알 수 있는 아이템·콤보를 관측 능력치에서 빼고 후보 기여로 바꾼다. 출처를 재현하지 못한 나머지는 관측값에 고정하며 이를 누락 안내에 명시한다. 이것은 모든 게임 효과를 재현하는 완전한 전투 시뮬레이터가 아니다. 지원·추정·미반영 범위는 [사용 안내](DPS.md)에 구체적으로 구분했다.

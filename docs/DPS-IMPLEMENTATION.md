# DPS 전환 작업 기록

2026-09-10 사용자 요청으로 진행했다. 게임은 설치본 1.0.30, DLL SHA-256은 `c3939a7d431f1362daca655938480569e11f501f7d0820a989873765555a7c39`이다. 게임 규칙은 로컬 디컴파일, 계수는 실행 중 프리팹에서 읽는다.

## 확정한 동작

- 단일·다수 대상 선택, 기본 30초·마나와 충전 가득, 조건 변경 가능.
- 사용자 공격 순서와 마법 우선순위 지정.
- 기본 활성·연결 보호 유지, 해제 가능. 개별 사용 유지와 고정은 별도 유지.
- 강화·양보 배수는 DPS에 적용하지 않음. 후속 요청에 따라 기본은 DPS 우선으로 하고 명시한 콤보·프리셋 강제 우선은 별도 선택으로 변경.
- 미반영 효과를 표시하면서 추천은 유지. 후속 요청에 따라 관련 아이템·주변·지원 연결·콤보 변화의 자동 적용은 기본 제한하고 별도로 허용 가능.
- 추가 대상 적중 비율, 단기·장기 프리셋, 초반·후반·빈 자원 시작 DPS 비교, 사용자 실측 평균 공격 간격 보정 추가.
- 지정 빌드 없음. 로컬 검사 뒤 게임 종료 상태에서 설치 허용. 인게임 실행·조작은 하지 않음.

## 구현

출처별 능력치 교체·제거와 증폭·원소 전환, 무기·볼트·볼루스파·화염검의 일부 공격, 공유 마나·시전·충전 사건 계산을 연결했다. 탐색의 후보 추정과 최종 배치, 획득·제외·합성 추천과 미리보기까지 예상 DPS를 사용한다. F2 전투·마법·DPS 내역, 설정 저장, 전투 입력 지문, 카탈로그 16을 추가했다. 재현 형식은 처음 2에서 후속 정책·구간 비교·시간 보정을 담는 3으로 변경했다.

현재 기여를 알 수 있는 아이템·콤보를 관측 능력치에서 빼고 후보 기여로 바꾼다. 출처를 재현하지 못한 나머지는 관측값에 고정하며 이를 누락 안내에 명시한다. 이것은 모든 게임 효과를 재현하는 완전한 전투 시뮬레이터가 아니다. 지원·추정·미반영 범위는 [사용 안내](DPS.md)에 구체적으로 구분했다.

## 검증과 측정

새 검사는 대시 패턴, 피해의 비선형 결합, 치명타 단위·처형, 공유 마나·우선순위·회복 지연·충전, 시작 자원·시간 경계, 영원의 식의 양쪽 플래그 교체, 화염검 자원, 출처 제거, 누락 허용, 취소·입력 오류를 다룬다. 작은 격자는 전체 배치를 열거해 솔버와 비교하고 가중치가 DPS에 섞이지 않는지 확인한다. 추천의 콤보 효과 중복 가산 방지, 설정 재저장·복사와 플러그인 JSON 재현도 검사한다.

.NET 10.0.401 SDK의 Release 테스트에서 측정한 합성 사례다. 게임 프레임 지연이나 실제 빌드의 전투 효율 측정은 아니다. 단일 무기 공격과 물리 피해·전체 피해 능력치 아이템을 사용했다.

| 사례 | 실행 시간 | 현재 스레드 할당량 | 모델 결과 |
|---|---:|---:|---:|
| 30칸·16 아티팩트·4 석판, 개선 전 단독 실행 | 905ms | 649.7MiB | 100 → 116 DPS |
| 같은 사례, 능력치 캐시·상세 생성 분리 뒤 단독 실행 | 641ms | 138.3MiB | 100 → 116 DPS |
| 42칸·35 아티팩트·6 석판 | 1490ms | 582.2MiB | 100 → 134 DPS |

마지막 실행에서 큰 사례 뒤에 실행한 작은 사례는 256ms였다. 워밍업·실행 순서 영향이 있어 단일 수치로 배속을 주장하지 않는다. 복잡한 마법·발동·가득 찬 가방의 다수 획득 후보는 별도 측정이 필요하다.

## 권장 방향 반영과 최종 검사·설치

사용자가 답변에 대한 재검토 의견을 요청한 뒤 권장 방향 전체 반영을 승인했다. 기본을 보호 조건 안에서 DPS 우선으로 변경하고, 콤보·프리셋 강제 우선은 별도로 켜도록 했다. 기존 지정은 삭제하지 않는다. 미지원 효과는 안내 문장의 존재로 일괄 차단하지 않고 해당 아이템의 상태·주변·지원 연결과 미지원 콤보 수량의 전후 차이를 검사한다. 적용 제한은 추천 생성과 분리하며 별도 허용도 기존 활성·레벨 검증을 우회하지 않는다.

추가 대상 적중 비율은 기본 50%의 비교용 추정이며 변경할 수 있다. 초반·후반 구간과 빈 자원 시작 비교를 추가하되 선택한 전체 구간 DPS만 추천 점수로 사용한다. 빈 자원 비교는 최종 현재·추천 배치에서 추가 계산하고 모든 탐색 후보에 반복하지 않는다. 단기 30초·자원 가득, 장기 120초·자원 비움 프리셋은 시간·시작 자원만 바꾼다.

사용자가 측정한 평균 공격 간격을 현재 공격 속도로 역산하는 보정을 추가했다. 후보의 공격 속도가 바뀌면 보정된 기본 시간에 새 속도를 적용한다. 측정 당시 무기 공격 목록과 다르면 보정을 적용하지 않는다. 실제 게임에서 간격을 수집하거나 피해 오차를 측정한 것은 아니다.

회귀 검사에는 기본 DPS와 명시한 빌드 우선의 순위 차이, 기존 설정의 기본 정책 변경과 지정 보관, 추가 대상 적중 상한, 구간 경계, 빈 자원 시작, 미지원 상태·이웃·멀리 연결된 침 사슬·콤보 변경, 별도 허용과 기존 검증의 독립성, 간격 보정 후 공격 속도 변화·무기 교체·잘못된 입력의 원자성을 추가했다. 재현 형식 3에 정책·구간 비교·보정값이 저장되어 같은 결과로 재생되는지 확인했다.

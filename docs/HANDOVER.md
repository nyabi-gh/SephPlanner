# 인계

직전 세션이 무엇을 했고 다음에 무엇을 할지. **[현재 상태](STATUS.md)가 정본이고 이 문서는 그날의 길잡이다.**
둘이 어긋나면 STATUS 를 믿는다. 세션마다 이 파일을 통째로 덮어쓴다 - 날짜별로 쌓지 않고, 제보별 조사 경위도
여기 남기지 않는다(결론은 해당 문서에, 경위는 커밋 메시지에).

## 2026-11-04 - 검토의 작은 수정 묶음 (Mac)

직전 인계 3번(검토 2026-11-04 의 작은 수정 묶음) 일곱 가지를 모두 넣었다. 추천은 바꾸지 않았다. 새 문구는 네 언어를 함께 넣었다.

- 화면
  - `45ffb81` 이동 안내가 쪽지처럼 1부터 센 "4열 2행" 과 "0° → 90°" 로 적힌다. 로그용 `GridPos.ToString` 은 그대로다.
  - `1c0b275` F2 빈 목록이 HUD 와 같은 사유를 띄운다(`Plugin.Blocked` 하나를 둘이 쓴다).
  - `59a0518` 안내문 화면에서 증가분 줄을 꺼 제목 밑 빈 줄을 없앴다.
  - `3fdaa31` 멀티 거절 사유가 설정 창 키와 ‘멀티 자동 배치’를 말한다. 정책과 적용기의 사전 검증이 한 문장(`AutoPlacePolicy.MultiplayerLocked`)을 쓴다.
- 성능
  - `dec621f` 콤보 셈 길의 이웃 사전을 구체 형으로 받아 열거자 상자를 걷었다. 한 번 부를 때 56 → 0 바이트다(.NET 10 임시 시험).
    `Exists(...Contains)` 대리자도 걷었다.
  - `61f35c2` 매 프레임 `Guarded` 에 넘기던 대리자 여덟을 필드에 담았다.
  - `97aa331` 가릴 오류 문장이 없으면 진단 `plan.replay` 를 다시 직렬화하지 않고 원본을 복사한다.
- 문서: STATUS "게임에서 아직 못 본 것" 맨 위에 "다음 판" 다섯 줄(위 넷과 `f3813b2`), ROADMAP 에서 끝낸 항목 정리, PERFORMANCE 1b.
- 확인: 이 Mac 에서 `scripts/check.ps1` 이 통과했다(형식, 테스트 1,029개, DataTool, 플러그인·창작마당 빌드 경고 0). 중간 커밋마다
  빌드하지는 않았고 마지막 트리만 봤다.
- 확인하지 못한 것: 게임 실기 전부, 보관 제보 47건의 `--reproduce` 대조(1b, 자료가 Windows PC 에만 있다), Mono 값.
- 아침에 넣은 `5eec9c4`(제보 `478fa937` 기록, RESEARCH)도 이번 푸시로 함께 올라갔다.

### 다음 판

번호는 정하지 않았다. 0.6.0 은 GitHub 공개와 창작마당 업로드가 끝나 태그를 옮길 수 없으므로 위 수정과 `f3813b2` 는
새 번호로 낸다. 번호를 정하면 [개발 문서](DEVELOPMENT.md) "배포" 대로 버전을 올리고, CHANGELOG 와 STATUS "다음 판" 다섯 줄의 판 칸을
고친다.
CHANGELOG 초안(사용자에게 보이는 것만):

- Changed: 이동 안내가 칸을 1부터 센 열·행으로, 회전을 도 단위로 적습니다.
- Changed: 멀티플레이에서 자동 배치를 거절할 때 켜는 곳을 함께 알려 줍니다.
- Fixed: 빌드 창 목록이 비었을 때 계산 중·데이터 준비 중에도 "탐험 중이 아닙니다." 로 뜨던 것을 고쳤습니다.
- Fixed: 안내문 화면에서 플래너 제목 밑에 빈 줄이 남던 것을 고쳤습니다.
- Fixed: 참가자로 자동 배치하는 도중 가방 칸이 늘면 오류 진단 대신 바뀐 가방으로 다시 계산합니다.
- (넣을지 판단) Changed: 조언 계산과 진단 수집이 쓰는 메모리를 줄였습니다.

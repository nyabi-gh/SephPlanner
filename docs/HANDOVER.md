# 인계

직전 세션이 무엇을 했고 다음에 무엇을 할지. **[현재 상태](STATUS.md)가 정본이고 이 문서는 그날의 길잡이다.**
둘이 어긋나면 STATUS 를 믿는다. 세션마다 이 파일을 통째로 덮어쓴다 - 날짜별로 쌓지 않고, 제보별 조사 경위도
여기 남기지 않는다(결론은 해당 문서에, 경위는 커밋 메시지에).

## 2026-11-24 - 1.0.33·BepInEx 판 정리 (Mac)

사용자 결정으로 0.6.7 부터 게임 1.1 이상, 창작마당에만 낸다. 모두 `main` 에 있다.

- **0.6.6 은 이미 공개돼 있었다**(GitHub 2026-11-19 08:03 UTC, ZIP 둘). STATUS 를 바로잡고 판을 0.6.7 로 열었다. 창작마당에
  올렸는지는 기록이 없다.
- **1.0.33 지원을 내렸다.** 게임사가 1.1 로 강제 업데이트해 1.0.33 은 할 수 없다(사용자 확인) - 그래서 1.0.33 사용자에게
  0.6.7 을 막는 업데이트 차단은 만들지 않았다. 플러그인은 나침반·개인 합성기·합치기 레시피를 이름 대신 직접 읽는다(1.1.4
  디컴파일로 필드 확인). Core 의 1.0.33 침 규칙은 옛 재현 자료를 위해 남겼다(사용자 결정, ROADMAP 4번).
- **BepInEx 판을 지웠다.** 창작마당 판을 `src/SephPlanner.Plugin` 으로 합치고(`WorkshopHost/`, `package/`)
  `src/SephPlanner.Workshop`·`BepInExHost`(게임 안 업데이트 포함)·`third-party`·ZIP 설치 안내·로더 스크립트를 지웠다.
  옛 BepInEx 판 설정 가져오기(`BepInExConfigImport`)는 남겼다. `make-release.ps1` 은 이제 패키지를 `WorkshopLocal` 에 놓고
  CHANGELOG 절을 변경 사항 글로 뽑는다. **GitHub 릴리스는 만들지 않는다** - 0.6.6 의 게임 안 업데이트가 없는 ZIP 을 찾다 실패한다.
- **개발사가 요청한 제보 안내가 창작마당 쪽에 없었다**(2026-09-03 요청, 그동안 ZIP 의 `INSTALL.txt` 에만 있었다). README
  다섯 언어와 `artifacts/workshop-description.txt` 에 넣었다.
- `check.ps1`(1.1.4)이 마지막 트리에서 통과했다(1133개). 바뀐 코드는 게임에서 못 봤다.

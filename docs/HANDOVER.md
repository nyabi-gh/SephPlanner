여기 남기지 않는다(결론은 해당 문서에, 경위는 커밋 메시지에).

## 2026-11-04 저녁 - 보관 제보 되살리기, 1b 대조, 창작마당 공개 (Windows)

- **보관 제보.** 47건은 이 PC 저장소에 없었다 - 옛 PC 의 `reports/` 에 있었고 그 폴더는 git 에 들지 않는다. 사용자가 그 폴더를
  압축으로 찾아 줘 `reports/` 에 풀었다. 재현 파일은 51건(옛 47건과 0.4.26 제보 넷)이다. 기기를 옮기면 이 폴더를 따로 옮긴다.
- **1b 대조 끝.** 작은 수정 묶음 앞(`f826556`)과 뒤(`ac5c786`)의 DataTool 로 51건을 `--reproduce --allow-model-change` 로 돌린
  출력이 "계산 코드 차이" 줄 말고 같았다. `6d50beb6` 의 warm 조언은 274 → 161MB 다([성능](PERFORMANCE.md) 1b).
- **창작마당.** 2026-11-04 에 검수가 승인됐고(`Player.log` 의 `[ModGuardReviewStatus]`), 사용자가 글을 공개로 바꾸고 설명을
  한국어·영어 한 칸으로 다시 넣었다. 게임이 올릴 때마다 설명을 `metadata.json` 으로 다시 쓴다는 것을 디컴파일로 확인해
  [게임 내부 조사](RESEARCH.md)와 [개발 문서](DEVELOPMENT.md)에 적었다.
- **확인.** 이 Windows PC 에서도 `scripts/check.ps1` 이 통과했다(테스트 1,029개, 플러그인·창작마당 판 경고 0). 이 PC 는
  `SEPHIRIA_DIR` 을 `C:\Program Files (x86)\Steam\steamapps\common\Sephiria` 로 줘야 한다.
- **게임 폴더.** `ac5c786` 빌드를 `WorkshopLocal/sephplanner/bin` 과 `BepInEx/plugins` 둘 다에 넣었다. BepInEx 는 꺼져 있다
  (`winhttp.dll.off`). 이 로컬 사본으로 "창작마당에 올리기" 를 누르면 버전 표기가 0.6.0 인 채 다음 판 DLL 이 올라가 검수가 새로
  접수된다. 게임 실기는 아직 하나도 안 했다.

## 다음 세션

   `artifacts/workshop-description.txt`(git 밖)에만 있다. `metadata.json` 의 `info.description` 에 넣으면 올릴 때 그대로 간다 -

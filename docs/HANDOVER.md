# 인계

직전 세션이 무엇을 했고 다음에 무엇을 할지. **[현재 상태](STATUS.md)가 정본이고 이 문서는 그날의
길잡이다.** 둘이 어긋나면 STATUS 를 믿는다. 세션마다 이 파일을 덮어쓴다 - 날짜별로 쌓지 않는다.

## 2026-09-17

최신 정식 버전은 원격에서 확인한 **0.4.6**이다. 이번 저주 합성 추천 수정을 **0.4.7 드래프트용**으로
준비한다. 제목은 `SephPlanner 0.4.7`, 태그는 `v0.4.7`이며 사용자 요청에 따라 공개하지 않고
드래프트로 둔다. 릴리스 본문은 [변경 기록](CHANGELOG.md)의 해당 절에서 배포 스크립트가 추출한다.

### 저주를 합성 재료에서 제외했다

해골의 시작 석판인 저주(12000)는 게임 데이터의 `cannotThrow`가 참이다.
설치된 게임 DLL을 디컴파일해 `UI_TabletMixPanel.AddItemToMix`가 이 속성의 재료를 거절함을
확인했다. 기존 추천은 합성 석판(2101)만 제외해 저주와 일반 석판의 합성을 제안했다.

`ItemCatalog.LoadTablets`에서 `TabletDefinition.CannotDiscard`를 읽고
`TabletMixAdvisor.Materials`에서 제외한다. 저주는 배치·효과 계산과 자동 배치 대상에 계속 남는다.
특정 아이템 번호에만 적용되는 예외를 두지 않았다. 자세한 근거는 [조사 기록](RESEARCH.md#합성-추천)에 있다.

카탈로그 형식은 **24**다. 저장 데이터가 새 속성을 담도록 다시 생성하며, 형식 23을 포함한 이전
진단 자료의 읽기는 유지한다. 이전 자료에는 제한 속성이 없으므로 당시 추천 동작으로 재현된다.

### 검증과 남은 확인

- 수정 전 추가한 회귀 테스트에서 저주가 합성 후보에 들어가는 문제를 확인했다.
- 수정 후 일반 석판끼리의 합성, 저주의 배치·효과·자동 배치 대상 유지, 저장 데이터 왕복과 이전 형식 읽기를 확인했다.
- `scripts/check.ps1`: 테스트 782개, 포맷 검사, 진단 도구와 게임 플러그인 빌드 통과.
- NuGet 취약성 정보 서버 접속 경고가 있었다. 실제 게임 화면에서 저주 합성 추천이 사라지는지는 아직 확인하지 않았다.

0.4.6의 망원경 배치 수정과 검증은 [수정 기록](notes/TELESCOPE-PLACEMENT-2026-09-16.md)에 남아 있다.

# 인계

직전 세션이 무엇을 했고 다음에 무엇을 할지. **[현재 상태](STATUS.md)가 정본이고 이 문서는 그날의 길잡이다.**
둘이 어긋나면 STATUS 를 믿는다. 세션마다 이 파일을 통째로 덮어쓴다 - 날짜별로 쌓지 않고, 제보별 조사 경위도
여기 남기지 않는다(결론은 해당 문서에, 경위는 커밋 메시지에).

## 2026-10-13 - 0.4.24 솔버 목적함수 통합, 고사양 모드

**0.4.24 는 드래프트다(미공개).** Windows ZIP 만 올렸다. Mac ZIP·실기·공개가 남았다.

제보 넷(`2b88c3a6` 혈석 귀걸이, `008cffa4` 자물쇠·당근, `1047183d` 영원의 식, `824bb145` 메모 없음)을 보관하고
처리했다. `1047183d` 는 이미 `0eccf4b` 가 경고로 다뤘고 `824bb145` 는 이상이 없다.

- **★ 가 줄어드는 패널티에도 걸린다.** 혈석 귀걸이처럼 레벨이 오르며 패널티만 줄어드는 아티팩트. 배수 1 에서
  식이 원래와 비트까지 같다 - 덧셈 순서만 바꿔도 무관한 판의 답이 흔들렸다([배치 평가](PLACEMENT-OBJECTIVE.md)).
- **탐색 단계가 한 목적값으로 견준다.** 배정에 지정 대상·지정 콤보 단계를 넣고, 화면 점수(`Score`)와
  비교용 목적값(`Objective`)을 나눴다. 다듬기에 쫓아내기(`TryEject`)를 더했다.
- **고사양 모드(F3, 기본 꺼짐).** 빔 확장을 여러 스레드로 나눈다. 답은 같다([성능](PERFORMANCE.md) "끝난 것").
- **버린 실험.** 배정 값에 눈금을 씌우기와 1e-9 반올림(둘 다 개선보다 악화가 많음), 빔에 지정 대상·콤보를
  넣기(빔 10배로 넓혀도 상위 단계가 바뀐 판이 없어 잴 이득이 없음), 콤보 탐색의 재배정(실패하는 판을 못 만듦).

검증: `scripts/check.ps1` 통과(949개, 경고 0). 보관 제보 47건, 종료 코드 0 스물둘 / 2 스물다섯.

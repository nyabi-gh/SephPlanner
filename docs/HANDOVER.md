# 인계

직전 세션이 무엇을 했고 다음에 무엇을 할지. **[현재 상태](STATUS.md)가 정본이고 이 문서는 그날의 길잡이다.**
둘이 어긋나면 STATUS 를 믿는다. 세션마다 이 파일을 통째로 덮어쓴다 - 날짜별로 쌓지 않고, 제보별 조사 경위도
여기 남기지 않는다(결론은 해당 문서에, 경위는 커밋 메시지에).

## 2026-11-02 - 자동 제보 셋, 진단의 게임 로그, 화면 번역

0.5.0 은 2026-10-30 에 공개됐다. 이번 세션의 커밋은 `main` 에 푸시했고, 다음 판은 열지 않았다(버전·CHANGELOG 그대로).

- **자동 제보 셋**(`3f51b7fd` 1.1.1, `baaeef81`·`fcb59d8d` 1.0.33). 코드는 고치지 않았다. 둘은 원인을 못 밝혀 STATUS 의
  "원인을 모르는 채 남은 것" 에, 하나는 고칠 수 있는 빈틈이라 ROADMAP "런타임·업데이트" 의 "조건 칸이 낡은 석판" 에 적었다.
- **진단에 게임 경고·오류**(`0457ec7`, `00ab644`). 유니티 로그의 경고·오류·예외만 `sephplanner.log` 끝 `[게임 경고·오류]`
  절로 싣고, 로비 비밀번호·닉네임·스팀 번호 등을 가린다. 항목이 늘어 동의 열쇠의 `DisclosureVersion` 을 올렸다 - 이미 동의한
  사람에게도 다시 묻는다. 서버는 그대로다. 방침은 [진단 전송](DIAGNOSTIC-UPLOAD.md).
- **화면 번역**(`8febdf2`). 영어·일본어·간체·번체. 기반과 규칙은 [개발 문서](DEVELOPMENT.md)의 "번역", 문구는
  `src/SephPlanner.Core/Text/Strings.*.cs`(506줄). 영역별로 서브 에이전트 다섯이 옮기고 번역했고 합치며 중복 12개와 용어를
  맞췄다. 원어민 검수는 없다. AGENTS.md 의 언어 규칙이 바뀌었다.
- **README 번역**(`4e4c176`). `README.*.md` 넷과 언어 전환 줄. 인용한 화면 문구는 실제 번역과 맞췄다.

검증한 것: `check.ps1` 을 지금 설치본(1.1.1)과 1.0.33 사본(`C:\Users\Nyabi\Documents\Sephiria-1.0.33`) 양쪽에서 통과(1004개,
경고 0). `reports/` 넷과 제보 `fcb59d8d` 의 `--reproduce --allow-model-change` 가 모두 종료 0 - 한국어 결과는 그대로다.
게임에서는 아무것도 보지 못했다.

## 다음 세션

1. **다음 판 열기와 릴리스.** CHANGELOG 에 진단 동의 다시 묻기와 화면 번역을 플레이어 말로 적는다. 공개는 사용자가 정한다.
2. **실기.** STATUS 표 맨 위 두 줄 - 번역(글꼴·폭·언어 전환)과 진단 게임 로그(동의 창·가림). 영어 폭은 F2 의 `Needle/Hourglass/Star first`,
   후보 안내 줄, F3 단축키 줄이 가장 빠듯하다.
3. **조건 칸이 낡은 석판**(ROADMAP). `AppliedRangeStale` 이 조건 질의도 게임 `ParseQuery` 와 견주게 한다.
4. STATUS 표의 0.5.0·0.4.27·0.4.26 실기 줄.
5. 이전 인계에서 남은 것: `[perf]` 로 정할 빔 열쇠 둘, 진단 자료 가림, 자동 진단 수집 계측, `Guarded`, `CharmCriteria.ReadsNeighbors` 시험.

**문서를 새로 만들기 전에** STATUS 의 문서 지도에 들어갈 자리가 있는지 먼저 본다. 날짜가 붙은 보고서 파일은
만들지 않는다.

# 아티팩트 선호도와 사용 유지

## 평가 기준

능력치 표를 환산할 때 이득과 패널티를 합산하기 전에 따로 보존한다. 가중치는 `이득 × 배수 + 패널티`로 적용한다. 패널티는 음수이며 배수로 커지거나 약해지지 않는다. 배수가 1이면 기존 순가치를 유지한다.

조화의 수정, 이웃 강화, 행 효과, 위치 의존 콤보 효과에도 같은 가중치 규칙을 적용한다. 조화의 수정의 게임 규칙은 로컬 1.0.30 `Assembly-CSharp.dll`의 `Charm_NearLevelDamage`를 확인했다. 이웃 8칸의 아티팩트 레벨은 각자의 상한에서만 자르고 음수는 남긴다. 자기 레벨의 계수를 곱한 뒤 내림한 전체 피해 보너스를 환산한다.

측정하지 못한 효과의 레어도 추정 하한은 이득에 보충하고 측정한 패널티는 남긴다. 직접 입력한 순가치나 이득·손해 분리가 없는 표에서는 알려진 순가치의 부호만 사용한다. 원래 능력치별 내역을 복원한 것처럼 취급하지 않는다. 카탈로그 형식은 10이며 새 덤프에 분리된 표를 저장한다.

이는 전투 시뮬레이션이 아니라 기존 능력치 환산 기준에 사용자 선호를 반영한 평가다. 체력·회피의 실제 효용과 모든 특수 효과를 정확히 안다는 뜻은 아니다.

## 사용 유지

빌드 창의 사용 유지는 소유한 같은 종류의 아티팩트 전부에 적용된다. 활성 상태를 유지한 개수를 점수보다 먼저 비교한다. 배정, 반복 수렴, 자리 교환, 콤보 탐색에서 같은 우선순위를 사용한다. 제한 해제 칸을 요구하는 기존 고정과는 별도다.

지정한 아이템을 제거하거나 교체하는 추천은 제외한다. 다른 아이템이나 석판을 바꿔 지정 아이템이 꺼지는 추천도 제외한다. 조건을 만족하는 배치를 찾지 못하면 대상과 확인된 비활성 사유를 알리고 수동 이동 안내와 자동 배치 목표를 비운다. 자동 적용 정책도 별도로 차단한다. 탐색 실패를 배치 불가능의 증명으로 표현하지 않는다.

## 탐색과 검증

자리 교환은 후보의 점유 상태와 석판 효과를 다시 계산하고 평가한다. 현재 배치도 유효한 후보라면 비교에 포함한다. 제한된 탐색이므로 모든 가방에서 전역 최적해를 보장하지 않는다.

회귀 검사는 양·음수 능력치의 분리, 기본 배수의 순가치 보존, 조화의 수정의 양·음수 이웃 효과, 사용 유지와 점수의 충돌, 칸 부족·무기 불일치·배치 조건, 교체 추천, 자동 적용 차단, 설정 저장과 계획 무효화를 다룬다. 6칸 조화의 수정 사례는 720가지 배치를 열거한 점수와 비교하고 동일 상태 재계산의 배치 안정성을 확인한다.

2026-09-08 로컬 게임 1.0.30 카탈로그로 0레벨 활성 칸과 -1레벨 비활성 칸을 비교했다. 경쟁 아이템 가치는 5로 고정했다. 경비병 모자는 기존 10배에서 비활성으로 배치됐으나 변경 후 활성으로 배치됐고 점수는 11.3333이었다. 유리망치는 10배에서 변경 전후 모두 활성이고 점수는 6.9231에서 9.6923으로 달라졌다. 기본 배수 1의 결과는 유지됐다.

같은 카탈로그의 세 종류 아티팩트 12개와 석판 3개를 사용한 42칸 합성 사례에서, 준비 실행 2회 뒤 7회 측정한 중앙값은 변경 전 90.2ms, 변경 후 89.8ms였다. 할당량은 약 132.46MB에서 134.18MB로 늘었고 기본 배수 점수는 같았다. .NET 10 로컬 비교이며 Unity 게임 내 성능이나 실제 멀티플레이 검증을 대신하지 않는다.

# 재현 지문 회귀 입력

세 JSON은 게임 자료가 아닌 합성 입력이다. 아티팩트 하나와 물리 피해 100의 무기, `0.85f`·`0.251f`를 double로 옮긴 관측 시간, `1.000030517578125f`의 무기 동작 시간, `0.2f`의 추가 적중 비율, `0.1f`의 실측 시간, `0.85f`·`0.1`의 수동 가치로 구성했다. 관측값뿐 아니라 설정 사전과 수동 가치도 런타임 사이에서 지문이 유지되는지 검사한다. 무기 동작 시간은 Mono와 .NET의 G15 반올림 방향이 갈리는 경계다.

- `replay-v5-mono.json`: 0.3.0 Core DLL을 설치된 게임의 Mono에서 실행하고, 게임에 포함된 Newtonsoft.Json으로 저장한 형식 5 본문.
- `replay-v5-net10.json`: 같은 Core DLL과 합성 입력을 .NET 10에서 실행해 저장한 대조 본문.
- `replay-v6-mono.json`: 지문 수정 후 Core DLL을 같은 Mono에서 실행해 저장한 형식 6 본문.

실행은 2026-09-10에 게임의 `mono-2.0-bdwgc.dll`을 별도 검사 프로세스에 로드해 수행했다. 게임 실행·UI·실전 피해를 검사한 자료는 아니다. 원본 `.replay`에서 외부 파일 표식과 본문 해시만 제외했으며, 숫자의 JSON 표기를 그대로 보존했다. 저장된 코드 식별자와 지문은 수정하지 않는다. 테스트는 코드 변경을 명시적으로 허용하되 입력 지문과 기준 결과를 검증한다.

`FingerprintNumberTests`의 기준 문자열도 같은 Mono에서 직접 출력해 기록했다. 중간값의 반올림 방향, G15의 자릿수 넘김, R의 G17 전환, 음수·0·최소 양수·최대 유한값을 포함한다.

# 런타임 재현 회귀 자료

두 JSON은 설치된 게임의 Mono 런타임에서 인공 입력으로 생성했다. 실제 플레이 기록이나 게임 자산은 포함하지 않는다.

- `replay-v1-mono.json`: 수정 전 0.2.8 Core, 카탈로그 15. Mono의 숫자 표기로 생성한 지문이다.
- `replay-v9-mono.json`: 공통 수정과 천칭 보호를 적용한 Core, 카탈로그 20. 표준화한 숫자 지문이다.

원래 작업 공간의 기준 작업 사본 내 `artifacts/release-audit/mono-old/`, `mono-new/`에 생성용 프로그램을 보관했다.
게임의 Mono 임베딩 런타임을 별도 프로세스에서 사용했고 게임 자체를 실행하거나 플레이하지 않았다.
두 파일 모두 `--allow-model-change`에 해당하는 재생과 입력 변조 거부를 테스트한다.
